# 고객 쇼핑 디자인 시스템

적용: 고객 홈 `/`, 상품 목록 `/products`, 상세 `/products/{id}`, 고객 공통 헤더·푸터. 공통 토큰·접근성은 [공통 디자인 시스템](design-system.md), 업무 화면은 [관리자 디자인 시스템](design-system-admin.md)을 따른다.

## 시각적 방향
의류 이미지와 상품 자체가 먼저 보이는 편집형 쇼핑 화면이다. 큰 이미지·명확한 타이포그래피·여백·절제된 강조색으로 브랜드 분위기를 표현한다. 시각적 강조는 실제 상품과 컬렉션에 사용한다. 관리 코드·개발 상태·가짜 할인·검증되지 않은 판매 문구를 넣지 않는다.

- 헤더는 브랜드와 핵심 탐색을 간결하게 배치한다. 상품 탐색에 불필요한 반복 메뉴/복귀 버튼을 큰 박스로 나열하지 않는다.
- 목록은 상품 카드 이미지가 주정보다. 상품명·입력된 가격·품절 상태만 간결하게 이어진다. 긴 상품명은 읽을 수 있게 줄바꿈한다.
- 상품 사진 영역의 일관된 비율과 충분한 크기를 유지한다. 중요한 의류 부분을 가리지 않는다. 상세 이미지는 전체 형태를 볼 수 있어야 한다.
- 고객 전용 클래스/토큰으로 범위를 제한한다. 고객용 변경으로 관리자 폼·재고 표·공장 메뉴의 크기/간격을 바꾸지 않는다.
- 모바일 일반 글자 크기는 상품 비교가 가능한 카드 배치를 우선하고, 큰 글자에서는 폭을 확보하기 위해1열 전환을 허용한다. 텍스트를 작게 줄여 억지로2열을 유지하지 않는다.
- 짧은 hover 전환은 선택 가능성을 보조한다. 키보드 포커스가 동등하게 명확해야 하며 reduced-motion을 존중한다.

## 검색·상세 필터 — WB89 / R97
상품 검색과 필터 토글을 기본 탐색 도구로 제공한다. 상세 설정은 **기본 닫힘**이다. URL에 조건이 있어도 자동으로 전체 설정을 펼치지 않는다.

1. 검색창과 검색 실행 동작은 항상 보인다. 상세 필터 토글은 아이콘+이름·적용 개수로 식별한다.
2. 카테고리·색상·사이즈·재고·정렬·페이지당 개수는 접힌 상세 설정 안에 둔다. 결과 개수는 목록 위에서 간결하게 유지한다.
3. 선택한 필터는 접힌 상태에서도 작은 조건 칩으로 보여주고 각 조건 해제와 상세 필터 초기화를 제공한다. 검색/컬렉션 문맥을 의도치 않게 지우지 않는다.
4. 검색·필터·정렬·페이지 크기 변경은 첫 페이지로 돌아간다. 열기/닫기만으로 URL·선택값·페이지가 바뀌지 않는다. 상세 복귀 시 URL 조건을 유지한다.
5. 토글은 실제 button, aria-expanded와 aria-controls로 상태와 대상을 연결한다. 접힌 영역의 컨트롤은 탭 순서에서 제외한다. 패널을 키보드로 닫으면 토글로 포커스를 돌려준다.
6. 드롭다운이 열린 상태에서 Escape는 먼저 드롭다운을 닫는다. 패널과 드롭다운이 동시에 예상 밖으로 닫히지 않도록 검증한다.
7. FormSelect는 공통 스타일 범위와 실제 라벨 연결을 유지한다. native select와 커스텀 trigger의 중복 표시를 허용하지 않는다.

## 상태와 상품 상세
로딩·검색결과 없음·게시중지/없는 상품·통신 실패를 구분한다. 고객에게 기술적 API 정보나 재고 원장을 표시하지 않는다. 가격 미입력을0원으로 바꾸지 않는다. 옵션은 실제 활성 조합만 제공하며 품절을 문구로 표시한다. 주문·결제가 미정인 현재 동작하지 않는 구매 버튼을 넣지 않는다.

## 검증 기준
기본/조건있는URL에서 접힘, 조건 칩·해제·초기화, 검색 입력 유지, 페이지 초기화, 키보드/포커스, 실제 상품 링크를 검증한다. 1440px/390px·밝음/어두움·실제16px/24px 글씨에서 이미지·값·간격과 가로 넘침을 확인한다. 화면 캡처를 직접 검토하며 단순 DOM 테스트만으로 시각 품질 통과를 선언하지 않는다.

## 고객 전용 구현 토큰 — WB89
범위는 `.shop-home`, `.shop-products`, `.shop-detail`, `.customer-header`, `.customer-footer`다. `--shop-accent`와 `--shop-tint`는 공통 글자/표면색에 따뜻한 중성색을 소량 섞어 테마를 따른다. `--shop-image-radius:8px`은 이미지, `--shop-control-radius:999px`은 간결한 탐색 도구에 적용한다. 서로 다른 목적의 이미지/컨트롤 모서리를 구분하되 같은 종류 안에서는 통일한다. 관리자 전역 토큰은 변경하지 않는다.

상품명·가격·필터의 읽어야 할 텍스트는 기본14px 이상에 해당하는 rem을 사용한다. 상품 색상 등의 짧은 보조 정보는 최소12px, 모바일의 장식용 브랜드 부제는 작게 압축하기보다 생략할 수 있다. 폰트 설정을 키우면 이 값들도 함께 커진다. 여백과 접힘 구조로 밀도를 줄이고 필수 정보를 지나치게 작게 줄이지 않는다.

## 가격·리뷰·평점 — WB91
상품 카드·상세 상단은 `리뷰 0건`으로 간결하게 표시하며 빈 평점을0.0점으로 만들지 않는다. 리뷰가 있으면 별 아이콘과 평균/리뷰 건수를 함께 표시하고 상세 상단 요약에서 하단 리뷰 영역으로 이동한다. 상세 빈영역은 긴 안내를 허용한다. 가격은 입력된 금액만 강조하고 가격 없음과0원을 구분한다. 로딩/실패를 리뷰0건으로 대체하지 않으며 재시도 경로를 제공한다. 별점은 숫자로도 읽을 수 있어야 한다. 구매 인증을 할 수 없는 상태에서 동작하지 않는 작성 버튼을 보여주지 않는다.

## 판매 가격·할인 — WB92
고객 홈·상품 목록·상세의 가격에는 판매 가격 라벨을 명시한다. 할인시 기본 판매가격은 취소선과 기본가격명으로 구분하고, 할인율/최종 판매가격을 가장 눈에 띄게 표시한다. 숫자만 나열하거나 색상만으로 차이를 표현하지 않는다. 작은 할인에 정수할인율0%를 노출하지 않으며 금액으로 차이를 전달한다.0원과 가격 미입력은 다르다. 공통 가격 컴포넌트를 사용하며 모바일·큰글씨에서 라벨/취소선/최종금액이 겹치지 않아야 한다.
