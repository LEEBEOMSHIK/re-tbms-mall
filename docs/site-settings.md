# 사이트 설정 설계

2026-10-26 / WB23 / R35

톱니바퀴는 사이트 이용 환경을 설정하는 공통 진입점이다. 글자 크기는 사이트 설정의 하위 기능이며 설정 창의 책임 전체가 아니다. 현재 화면 계층은 **사이트 설정 → 화면 및 접근성 → 글자 크기·화면 테마**다.

## 구현과 후보

| 분류 | 항목 | 상태 | 저장·권한과 선행 조건 |
|---|---|---|---|
| 화면 및 접근성 | 글자 크기 | 구현 | 현재 브라우저, 로그인 불필요, 기존 저장키 유지 |
| 화면 및 접근성 | 라이트/다크/시스템 테마 | 구현 (WB45) | 현재 브라우저 저장, 기본 시스템, 글자 크기와 독립 |
| 화면 및 접근성 | 동작 효과 줄이기·자동 넘김 선호 | 추후 후보 | 기존 OS reduced-motion 및 슬라이드 일시정지와 우선순위 결정 필요 |
| 알림 | 알림 종류·수신 방식 | 추후 후보 | 실제 알림 서비스·인증·서버 동의 기록·채널 계약 필요. 운영 메시지와 마케팅 동의 구분 |
| 언어 및 지역 | 표시 언어·지역 형식 | 추후 후보 | 지원 언어/운영 국가/통화 미정. 판매 정책을 이 설정으로 임의 확정하지 않음 |
| 개인정보 | 선택적 저장·분석 설정 | 추후 후보 | 실제 사용하는 분석 도구·쿠키·동의 정책이 확정된 경우에만 추가 |

후보는 확정 일정이나 구현 완료가 아니다. 현재 UI에는 사용 가능한 설정만 표시한다. 계정/비밀번호/보안 기능이 추가되면 인증된 계정 관리로 연결할지 별도 설계한다. 가격·재고·배송·운영 채널 등 사업 운영 설정은 관리자 권한을 서버에서 검증하는 별도 관리 기능이며 브라우저 개인 설정과 혼합하지 않는다.

## 컴포넌트 경계

- SiteSettingsButton/공통 대화상자: 진입, 제목, 닫기, 포커스, 반응형 배치만 담당한다.
- SettingsSection: 제목과 설명, 하위 설정 children을 받는 공통 분류 단위다.
- TextSizeSetting: 글자 크기 선택·현재 상태를 담당한다. TextSizeControl은 루트에서 저장 크기를 복원한다.
- 새로운 설정은 자체 값·검증·저장 계약을 가지며 해당 분류에 구성한다. 글자 크기 컴포넌트 안에 기능을 계속 덧붙이지 않는다. 현재는 React composition으로 충분하며 플러그인 레지스트리나 공용 DB 모델은 도입하지 않는다.

코드 위치는 apps/web/src/components/site-settings.tsx(공통 셸·분류), site-settings-content.tsx(구현 항목 조합), text-size-control.tsx(개별 글자 크기 기능)다. 새 기능은 SiteSettingsContent에서 적절한 SettingsSection의 자식으로 추가한다. 셸 자체는 글자 크기 저장 키나 값에 의존하지 않는다.

## 설정 추가 절차

1. 목적·사용자·분류·기본값·허용값·초기화 의미를 요구사항에 명시한다.
2. 브라우저/계정/사이트 운영 중 저장 범위를 선택한다. 계정/운영 값은 서버 인증·권한·충돌·실패 처리가 필요하다.
3. 즉시 반영과 저장 버튼 중 적합한 방식을 정한다. 브라우저 저장 실패 시 현재 화면만 적용되는지, 서버 저장 실패 시 되돌리는지 명시한다.
4. 기존 저장값 호환, 잘못된 값, 로그아웃/기기 변경, 키보드·모바일·최대 글자 크기를 검증한다.
5. 구현 완료된 항목만 노출하고 디자인 시스템·작업 보드·검증 기록을 갱신한다.

설정 개수가 늘면 분류별 탐색이나 별도 설정 페이지로 확장한다. 아직 한 개의 분류인 현재는 불필요한 빈 탭 없이 분류 제목과 항목을 표시한다.


## 테마 저장·초기 적용 (WB45)

re-tbms-mall:theme 키의 light/dark/system을 사용한다. 잘못된 값이나 저장값 없음은 시스템 설정을 따른다. 명시 선택은 OS 변화보다 우선한다. 시스템 모드에서는 실행 중 OS 변경도 반영한다. 다른 탭의 저장 변경을 동기화하고 저장 불가 환경에서는 현재 탭에 적용한다. HTML의 data-theme은 해석된 light/dark이며 첫 표시 전 초기 스크립트로 설정한다. 사이트 운영 설정이나 계정 설정은 변경하지 않는다.
