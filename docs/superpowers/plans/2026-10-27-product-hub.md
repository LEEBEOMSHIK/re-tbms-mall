# WB75 / R85 상품 상세 중심 관리

- 목적: 기본정보·옵션·재고 조회와 작업 진입을 상품 상세로 통합한다.
- 담당: root 상세/라우트/기준수정/문서, supplier_ui catalog-forms, supplier_review 독립검증.
- 계약: 기존 API 유지. InventoryForm optional productId로 대상 SKU 제한. 잘못된 상품은 다른 상품으로 대체하지 않는다.
- 화면: 상세의 기본정보/색상·사이즈/재고 구역, 옵션 페이지네이션, 부족기준 수정, 입출고·조정 별도 URL. 기존 옵션의 색상/사이즈 식별자 변경 기능은 도입하지 않는다.
- 저장: 상품등록·수정, 옵션등록, 기준수정, 상품에서 시작한 재고변경은 서버 확정 결과 후 상품 상세로 연결한다. 재고 메뉴 직접 등록은 기존 이력 복귀 유지.
- 수용: 화면분리, 상품문맥 유지, 성공결과/실패보존/모바일포커스, 직접URL인증, 부족 빨강/양호 초록, 기존 시안·이미지 유지.
- 검증: 타입/lint, 모의쓰기 브라우저 경로와 모바일/실패, 독립 검토. 실제 데이터 쓰기 금지.
- 복구: 해당 UI/라우트 변경 복원. API/DB변경 없음.
