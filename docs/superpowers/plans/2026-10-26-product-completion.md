# 상품 등록 완료 흐름

WB24 / R31·R36 / 2026-10-26

원인: 신규 저장 후 빈 등록 폼을 그대로 두고 상단의 작은 안내만 바뀌며 포커스/스크롤이 이동하지 않는다. 하단 등록 버튼을 누른 사용자가 성공과 다음 단계를 인지하기 어렵다.

서버의 정상 성공 응답을 받은 신규 상품만 완료 화면으로 전환한다. 상품 표시명·내부명, 기본 정보 등록 완료 및 색상·사이즈/재고 다음 단계를 명시한다. 주 동작은 저장된 상품ID로 색상·사이즈 등록, 보조 동작은 상품 목록으로, 반복 등록은 명시적 다른 상품 등록 버튼이다. 완료 제목으로 포커스/스크롤을 이동한다. 저장 중 버튼은 등록 중 표시와 잠금을 유지한다. 실패는 입력 유지/오류, 불확실 응답은 기존 저장 여부 확인 안내를 유지한다. 수정은 기존 수정 흐름을 보존한다.

UI 담당은 ProductForm/CSS, 조정 담당은 명세·문서·브라우저, 별도 검증자는 소스/테스트를 맡는다. API/DB/상품 게시·판매 규칙은 바꾸지 않는다. 수용 기준: 성공에만 완료/이름·ID·다음 단계·포커스, 실패와 수정 회귀, 모바일 큰 글씨, 반복 클릭 중복 방지. 브라우저 쓰기는 모의 응답으로 검증한다. 복구는 UI/문서 변경만 되돌린다. 선행 WB23.
