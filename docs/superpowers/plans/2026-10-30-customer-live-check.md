# WB101 / WB102 · R105 실연동 확인
목적: 실제 Google/Kakao 인증 진입·완료·취소·로그아웃 및 상품복귀/장바구니 유지 확인. 담당 root, 별도 독립 검증자. 기존 dirty 작업 보존.
범위: 실제 localhost3100/8100 연결을 사용하되 계정 입력은 사용자 직접 진행. 비밀/프로필 원문 기록 금지. 실제 장바구니 테스트는 기존 행 보존·테스트 변경만 복구. 공급자/고객별 격리·금액/재고 경계는 합성 임시DB 검증도 별도로 수행.
예상 파일: customer-auth-core/customer UI/API 중 확인된 결함 해당 파일, tests, 관련 계약/가이드, workboard 및 검증기록. 기존 인증/카트 계약 유지, 변경 시 문서 동기화.
수용: 공급자별 실제 성공/취소/로그아웃·상품복귀·카트영속 검증과 실제/합성 근거 분리. 운영도메인/공개상태는 외부 사용자 설정 없으면 미검증 유지. 결함은 재현→회귀검증→수정→독립검토.
가이드 영향: 관리자 업무 가이드는 고객 로그인 절차를 포함하지 않음. 고객 로그인 설정 안내/계약에 영향이 있으면 갱신. 업무/화면 변경 시 영향 재판정.
복구: 이번 변경 파일 내 수정만 되돌림. 실계정/기존카트/기존DB 삭제 없음.
