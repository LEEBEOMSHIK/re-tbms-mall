# WB49 / R59 공급처 저장·전화번호

- 목적: 공급처 등록·수정 후 목록으로 자동 복귀하며 전화 입력 오류를 저장 전·서버에서 검증한다.
- 범위/담당: supplier_ui apps/web 공급처 및 검증 helper/tests, supplier_api services/api validator/tests, 조정 docs/workboard, supplier_review 독립 실행·검토.
- 계약: 성공 응답을 검증한 후 목록으로 이동. 목록은 실제 조회한 id/version과 대조해 안내하고 조회실패/불일치는 성공으로 꾸미지 않는다. 실패는 입력을 보존한다.
- 전화: 선택 입력, 공백·하이픈·괄호·마침표를 제외한 ASCII 숫자 최대11. 선두 +는 국제형식 최대15. +중복/중간위치/문자/숫자없는 값 거절. 정확히11자리나 실제개통 검증은 아니다. 해외는 +국가번호 형식을 안내한다.
- 호환: 기존값 자동변환 없음. 수정 시 바뀌지 않은 전화는 보내지 않아 서버의 누락보존 계약을 사용한다. 바꾼 번호만 새 규칙을 검증한다. 국가와 독립된 연락처 형식이다.
- 수용: 생성·수정 자동이동, 목록 성공/미일치/조회실패, 양쪽전화 경계11/12 및15/16, 구분자/빈값/잘못된+·문자, 기존전화 누락보존, 입력오류/재시도, 모바일·간격.
- 검증: API 임시DB 테스트, 웹 단위/lint/type/build, Edge 모의저장·실제 페이지 렌더링. 사용자 DB에 테스트 저장하지 않는다.
- 의존성/복구: DB·외부서비스·새패키지 없음. 이번 화면/helper/validator 변경만 되돌리면 복구 가능. 이전 작업 변경은 보존한다.

저장 확정 응답의 최소 정보(id/version/name/is_active)는 일시적인 메모리 영수증으로만 유지한다. 목록 조회 실패 시 저장 성공과 조회 실패를 구분한다. URL만으로 새 저장이 확정되었다고 판단하지 않는다. 조회 대조는 동일 id 및 version 이상이며 더 최근 수정이 있으면 최신 목록 내용을 표시한다.
