# WB64 / R76 시안·샘플 작업 화면 분리

## 문제와 수용 기준
상품 상세에 공장 업무 변경폼·전체이력까지 섞였고 전체폭 저장버튼/과한공백/빈목록페이지가 기존 UX기준과 맞지 않았다. 상품 상세는 담당공장·상태·최근변경·작업화면 링크 요약만 유지한다.

## 경로/소유권
- 내부 /admin/factories/progress: 상품/공장/상태 검색필터 목록. [id]: 상태/이력 조회. [id]/edit: 상태·메모 변경만. supplier_api 신규파일 담당.
- 공장 /factory/products/[id]: 상품정보+작업요약. /progress:조회이력, /progress/edit:변경. supplier_ui 및 공통 ProductProgress mode summary/view/edit 담당.
- 조정: 기존 관리자 메뉴/상품요약 연결, 문서/작업보드/브라우저. supplier_review 독립검증.
- API/DB/권한/상태전이 변경 없음. 기존상품상세·공장상품 주소는 유지하고 업무 입력만 새경로로 이동.

## UX 계약
조회/변경을 분리하고 저장 성공시조회화면으로이동+확정receipt 기반 큰완료안내. 조회실패와저장실패구분, 실패입력보존/충돌재조회, 미배정은읽기전용이력 유지. 상단에상품정체성과목록복귀. 상세설명은?도움말로접근가능. 상태셀렉트와메모 라벨상단정렬, 간격토큰/주행동버튼 데스크톱내용폭·모바일1열. 빈이력은안내만보이고건수/페이지당개수/이전다음숨김. 데이터있는이력·관리목록 공통페이지네이션/검색필터1페이지유지.

## 검증/복구
웹 타입/린트/빌드·독립검토, 브라우저 상품상세요약만/목록검색필터/별도변경/저장복귀·receipt/실패·충돌/빈이력/라이트다크/모바일 확인. API업무는변경없으며 기존테스트근거와새UI검증구분. 변경컴포넌트·라우트만복원가능, 실제DB수정없음.
