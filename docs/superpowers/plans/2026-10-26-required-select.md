# 필수 입력 표시와 옵션 목록 디자인

2026-10-26 / WB19 / R18·R31·R34

사용자 요청: 필수 입력을 표시하고 펼친 콤보박스 옵션까지 스타일을 개선한다. 공통 FormLabel과 FormSelect를 사용해 catalog의 모든 선택 필드를 교체한다. 기존 native 옵션 목록은 OS 스타일이어서 이번 사용자 요청을 충족하려면 웹에서 그리는 listbox가 필요하다.

단일 선택 combobox: 펼침/선택/활성/비활성 상태, 선택 체크, 스크롤과 모바일 화면 경계. 키보드 화살표/Home/End, Enter/Space, Escape, Tab, 바깥 클릭을 지원한다. ARIA 이름/required/expanded/controls/activedescendant와 포커스를 확인한다. 임의 선택이나 제출을 하지 않는다. native 필수 검증 연결 또는 동등한 검증으로 빈값 제출을 막고 오류 필드에 포커스를 준다. busy/상위fieldset disabled도 옵션 변경을 막는다.

필수 표시: 고객 표시명, 신규/재분류 상품의 대분류·세부분류·계절, 옵션 대상/코드/색상/사이즈/재고기준, 재고변경 대상/수량/사유, 카테고리 이름/신규코드/정렬. 설명과 상위분류는 선택, 내부명은 자동생성. 기존 미지정 분류·계절을 그대로 유지하는 상품 편집 예외와 코드수정불가를 정확히 안내한다. 장식 마커가 accessible name을 오염시키지 않게 한다.

inventory_ui: components/ui 공통 컨트롤과 catalog 폼/테스트. inventory_review: 독립 구현/키보드/검증 경계 검토 및 웹 테스트/lint/types/build. 조정 담당: 문서·보드 및 실제 브라우저. API/DB/번호/계절 규칙은 바꾸지 않는다.

수용 기준: 필수/선택/자동 표시 일치, 빈 필수 선택 시 차단과 오류/포커스, 팝업 옵션 통일된 스타일, 키보드/닫기/비활성/빈 목록, 작은 화면 넘침 없음, 기존 legacy 편집/계절 로직 유지. 복구는 UI·문서만 되돌리며 데이터 영향 없음.
