# WB119 관리자 PG 도입 준비
요구 R112. root: Next 페이지·콘텐츠·공유문서, pg_menu_backend: 메뉴 API/테스트, 검증 별도 역할.
범위: /admin/payment-preparation 읽기 전용 안내, 문의문 복사, 준비정보, 카드/간편결제 구분 및 공식출처. 메뉴관리 등록, 기존8개 설정을 보존하여 새9번째 메뉴 제공.
계약: 관리자 세션 필수. 실제 견적 발송/계약/PG선정/고객결제 없음. 문의문 빈칸은 사용자가 외부 발송 전에 작성; 사이트 내 저장폼은 만들지 않음. 상태는 workboard만 단일 원본, 안내화면에서 정적 진행상태를 복제하지 않고 보드 링크 제공.
수용: 기본/기존 메뉴에서 링크 표시, 숨김은 권한 아님, 직접URL 비인증 차단, 복사 성공/실패 명시, 좁은 화면 넘침 없음. 가이드 pg-preparation 추가, 관련 start/nav 캡처는 메뉴 영향 확인.
검증: 메뉴API 합성DB, 웹 메뉴/가이드/보드 테스트, type/lint, 실제UI. 복구: 관련 코드 되돌리기, DB 읽기 정규화는 기존데이터 보존, 신규메뉴 설정 저장 이후에는 코드 동시복구 필요.

후속: 사용자 요청으로 토스/KCP/이니시스/포트원의 일반·간편결제/신청조건/출처 카드 추가. KCP는 포트원 경유 공식 지원표 기준을 명시. 상단 문의문/메뉴 캡처 위치 불변; guide pg-preparation의 비교단계 갱신. PC/모바일/독립검토 후 상태복원.
