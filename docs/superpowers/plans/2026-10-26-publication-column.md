# 게시 상태 컬럼과 상세 사유

WB29 / R39 / 2026-10-26. 준비 상태에서 미게시 배지를 분리해 게시 상태 컬럼을 만든다. 현재 고객게시 연결이 구현되지 않았으므로 모든 상품은 게시 불가다. 짧은 안내는 옵션미등록/재고없음이 있으면 이를 먼저, 그 외에는 게시기능준비중으로 표시하고 상세에는 고객게시미연결을 반드시 포함한다. partial재고를 전체게시불가의 새 업무규칙으로 단정하지 않는다. 서버준비집계에서 이미확인된 미완료작업을 설명하는 표시 변경이며 게시승인/자동게시/새API는 추가하지 않는다. 집계누락 시 준비상태미확인과게시미연결을 명시한다.

UI 담당: 별도 게시 td, 아이콘+게시불가배지, 짧은사유, 재사용 hover/focus/tap 상세툴팁. 내용에는상품명과현재옵션/재고내역,미완료작업과게시미연결을 구분한다. tooltip은 viewport를 벗어나거나 tableoverflow에 잘리지 않게 표시하고 Escape·바깥클릭·hover전환/포커스동작을 처리한다. 조정담당: 문서/보드/브라우저. 독립검증자: 소스/타입/lint. 수용: 준비/게시컬럼분리·4상태/unknown사유·hover/focus/mobile·Escape·표스크롤/화면경계·삭제회귀. 복구는UI문서만되돌린다. 선행WB28.
