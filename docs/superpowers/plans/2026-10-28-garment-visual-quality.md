# WB83 시각 품질 보완 계획 — 2026-10-28

사용자 피드백: 기존 3D는 저품질 게임의 각진 형상처럼 보이며 면/울의 느낌을 판단할 수 없다. 기존 승인된 원단/의류 미리보기 목적의 품질 수정이다. 기능 통과를 시각 품질 수용으로 취급하지 않는다.

## 원인과 수정 설계
평면 윤곽 양면을 돌출한 형상과 모든 원단에 동일한 작은 bump 패턴을 사용했다. 울 옵션이 없다. 폴리곤 수만 늘리는 방안은 형상/직물 근거를 해결하지 못한다. 기존 단일 문서와 2D 좌표는 보존하면서 곡면의 열린 의류 형태, 실제 원단 조직 기반 PBR 텍스처, 근접 확인 뷰를 적용한다. 현재 저장 디자인의 표면 ID/영역은 유지한다. 원단은 면 저지/울 부클레 등 구체 조직으로 이름을 표시한다. 정적 굴곡은 시각적 표현이며 물성 시뮬레이션이 아니다.

## 소유권/순서
1. garment_shape_v2: garment-geometry.ts + geometry tests. 곡면 몸판·열린 목/소매/밑단·봉제/시보리·후드 형상, 비대칭 프린트 UV 보존.
2. garment_material_v2: preview-3d.tsx, fabric-material.ts, 해당 tests 및 public/garment-materials. CC0 원단 파일을 로컬 저장, source/license/hash 기록, 미세 요철/거칠기/섬유 반사와 확대 보기. 외부 런타임 호출 없음.
3. root: model.ts 및 서버 models.py의 wool 프리셋, 왕복/잘못된 원단 실패 테스트, 문서·보드·실제 브라우저 통합 검증.
4. 독립 검토: 실제 수정과 실행 결과, 나염/후면/저장 보존, 텍스처 요청 실패 및 리소스 정리 확인.

## 수용 및 검증
- 같은 색·조명에서 면 저지와 울 부클레의 조직과 반사가 전체/확대에서 구분되어야 한다.
- 정면·사선·후면에서 상자 옆벽, 닫힌 소매 끝, 떠 있는 목 고리를 제거한다.
- 기존 2D 나염 좌표/좌우/레이어와 저장 문서를 보존한다. 서버 wool 저장/복원/미지원 값 거부를 검증한다.
- 단위 테스트·lint·타입·빌드와 실제 브라우저 캡처를 확인한다. 숫자 검사만으로 사실적 품질 통과를 주장하지 않는다.
- 수정 전후 캡처와 제한을 보고한다. 실제 원단 샘플의 정확한 복제나 드레이프는 아직 지원하지 않는다.
- 별도 worktree 3102/8102 유지. 원본 앱/다른 서버/DB 변경 없음. 소스 통합 및 worktree 정리는 기존 절차를 따른다.
## 실제 화면 검토 후 변경
사용자는 몸에 입힌 상품 촬영 형태(마네킹 숨김)를 선택했다. 절차형 곡면 보완도 실제 화면에서 어깨가 부자연스러워 최종 모델로 수용하지 않는다. MakeHuman Community의 작가 제작 티셔츠(Margaret Toigo/MRT, CC0)와 후드(Elvaerwyn, CC-BY)를 사용한다. 출처 OBJ/라이선스 헤더·해시·변환 스크립트를 보존하고 공식 배포 출처와 변경 내용을 기록한다. 원본 패키지 전체·불필요 썸네일·조사 자료는.local에만 둔다.

의류 원본 비례를 보존하고, 기존 2D 문서의 인쇄 영역을 실제 몸판 영역으로 대응시키는 템플릿별 변환을 사용한다. 월드 좌표는 저장 계약이 아니다. 원단 normal/roughness와 작은 diffuse 명암만 적용하며 원본 직물의 체크 염색 무늬가 사용자의 단색을 덮지 않도록 넓은 명암 무늬를 제거한다. 나염은 원단 합성 이후 그려 원본 디자인 색을 보존한다.

원단 비동기 전환이 업로드 나염을 지우는 회귀를 독립 검토에서 찾아 최신 asset key를 참조하도록 수정했다. 정상/실패 캐시 해제 및 후속 재시도를 검증한다.
