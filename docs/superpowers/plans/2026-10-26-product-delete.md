# 상품 삭제와 목록 작업 UI

WB25 / R37 / 2026-10-26

상품 목록의 수정·색상/사이즈 작업을 공통 라운드 아이콘+라벨 버튼으로 정돈하고 별도 삭제 진입과 확인 모달을 제공한다. 삭제 대상 상품명·내부명을 보여주고 취소를 기본 포커스로 둔다. 진행/실패/성공을 구분하고 취소는 요청하지 않는다. 성공은 해당 행 제거/목록 갱신 및 안내, 실패는 유지한다.

계약: DELETE /api/v1/admin/products/{id}, JSON {version: nonnegative strict integer}, 인증 필수. 동일 BFF DELETE /api/admin/products/{id}는 세션/Origin/본문 검증과 기존 proxy 보호를 사용한다. 성공200 {id,deleted:true}. 없음404, 오래된version409, 연결SKU존재409, 입력422, 인증401. 연결SKU가 하나라도 있으면 재고0이어도 삭제하지 않는다. 서버 BEGIN IMMEDIATE 안에서 version+SKU 검증+삭제. 생성 내부명 번호 카운터는 되돌리지 않는다. FK/ledger는 손대지 않는다. 실제 상품 데이터는 테스트로 삭제하지 않는다.

backend 담당은 API/테스트, UI 담당은 catalog-list/manager/css, 조정 담당은 BFF/문서/브라우저, 독립 검증자는 통합 소스/실행 결과를 확인한다. 파일소유권 분리. API계약 변경 시 조정 담당에게 전달. 수용: 권한/경합/연결차단/번호재사용없음, 취소/성공/실패, 모바일·키보드, 수정/옵션 링크 유지. 삭제된 무연결 상품은 복구 UI가 없음을 확인창에 안내한다. 데이터복구는 별도 백업 필요, 배포/실데이터삭제 없음.
