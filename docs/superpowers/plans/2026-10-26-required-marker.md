# 필수 입력 기호 변경

WB20 / R34 / 2026-10-26

목적: 반복되는 필수 텍스트를 라벨 옆 별표로 줄인다. 조정 담당은 FormLabel·폼 안내·디자인 문서·보드를 수정하고 별도 검증자가 결과를 검토한다. 공통 FormRequiredHint를 상품/옵션/재고/카테고리 폼 상단에 한 번씩 배치한다. 선택·자동 생성·변경 시 필수 안내와 required/aria-required 검증 계약은 유지한다. API/DB 변경과 의존성 추가는 없다.

수용 기준: 필수 라벨에 * 표시, 폼별 안내 한 번, 접근성 이름과 검증 유지. 타입 검사·독립 소스 검토·기존 브라우저 스모크의 표시 기대값 갱신 후 실행으로 검증한다. 복구는 이번 UI/문서만 되돌린다. 선행 WB19.
