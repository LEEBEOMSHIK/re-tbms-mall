# WB85 / R93 공장 본인 프로필 수정

사용자는 관리자가 발급한 공장 계정의 변경 가능한 정보를 본인이 수정하도록 요청했다. 기존 모델의 이름과 비밀번호를 편집 대상으로 한다. 아이디·소속·권한·활성 상태는 변경하지 않는다. 전화·이메일 등 신규 개인 정보 필드는 이번 범위에 추가하지 않는다.

## 담당·경계
root는 문서/통합, profile_api는 services/api, profile_ui는 apps/web, 독립 검증자는 실제 소스와 실행 결과를 검토한다. C:/projects/re-tbms-mall 기존 로컬 서버에 구현하며 기존 다른 작업을 보존한다. 추가 worktree/운영 배포/DB 마이그레이션 없음.

## 계약
GET/PUT /api/v1/factory/profile → {account,supplier_name}. PUT {display_name,version,current_password?,new_password?}. 표시명 공백 제거 후1..80, 비밀번호 변경 시 현재 비밀번호 필수 및 신규12..128. extra forbid, 서버 세션에서 본인 계정 결정. 변경 버전 충돌409; 현재 비밀번호 오류422; 반복 오류429. 비밀번호 변경 시 다른 세션을 만료하되 요청 세션 유지. Next BFF 인증·Origin 확인.

## 화면·수용 기준
프로필 카드에서 별도 /factory/profile/edit 이동. 이름 강조, 변경 불가 정보는 읽기 전용. 비밀번호는 선택 구역으로 분리하며 재입력 확인. 성공은 서버 확정 이름·후속 대시보드 이동을 SaveResult로 표시. 실패 입력 보존/중복 제출 방지, 저장 성공 이후 조회 실패를 구분. 모바일·다크·큰 글씨 및 완료 포커스 확인.

## 검증
임시DB에서 본인 범위·불변 필드·잘못된 비밀번호·버전 충돌·다른 세션 만료 테스트. UI는 합성 응답으로 성공/오류/충돌/민감값 처리 확인하며 실제 로컬 테스트 계정 비밀번호를 변경하지 않는다. 타입/lint 및 독립 브라우저 검증. 기존 업무 데이터 미변경. 복구는 추가 경로/수정 UI 및 서버 메서드만 되돌린다.

## 후속 저장 동선
사용자 요청: 완료 화면 없이 서버 확인 후 /factory replace, 일회성 메모리 저장 알림, 홈 제목 대시보드. root 구현, factory_verify 독립검증. 수정 파일 profile-edit/workspace/shell CSS 및 lib/factory-profile-feedback. 성공 자동복귀·알림/포커스·재방문 미반복·실패 화면유지 확인. API/권한 변경 없음.

후속 탐색 정리(R92/R93): GNB와 중복인 일반 헤더 대시보드로 링크 제거, 프로필 편집 취소는 기능 유지/라벨 축약. root 구현, 별도 검증자 소스·브라우저 확인. workspace/profile-edit 두 파일만 변경, API 변화 없음. 수용 기준: 목록/상세의 중복 링크 없음·사이드바 대시보드 이동·편집 취소 유지.
