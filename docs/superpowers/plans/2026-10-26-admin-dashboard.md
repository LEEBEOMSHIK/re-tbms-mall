# 관리자 업무 현황 대시보드 계획

날짜: 2026-10-26 / 요구 R30 / WB12
목적: 관리자 홈을 메뉴 목록에서 업무 현황 확인 화면으로 확장한다.

범위: 처리할 업무, 접수 Q&A, 의류 입고, 배송 상태, 재고 부족 요약 및 목록. 기존 진열·작업 보드 접근 유지. 실제 업무 데이터 저장/외부 배송/주문/결제는 아직 없으므로 고정 시점 합성 샘플로 표시하며 실제 처리 기능으로 표현하지 않는다.

설계: FastAPI 인증된 읽기 API /api/v1/admin/dashboard에서 샘플 데이터와 동일 목록 기반 요약 수치를 제공한다. Next /api/admin/dashboard는 기존 세션으로 중계한다. /admin은 로그인 후 요약·우선 업무·각 영역 상태 목록과 필터를 제공한다. 재고 가용수량=보유-예약, 부족 SKU는 가용수량<=샘플 기준값으로 계산하며 실운영 재주문 정책 확정이 아니다.

분담: dashboard_api 서비스·합성 데이터·권한/집계 테스트; dashboard_ui 화면·중계·필터·오류/로딩; 조정 문서·브라우저; 독립 검토 담당 소스 및 테스트/빌드.

수용 기준:
- [x] 로그인 없이 대시보드 API 접근 거부
- [x] 다섯 업무 영역 및 실제 목록과 일치하는 요약 제공
- [x] 샘플과 기준 시점 명시, 개인정보·실거래 없음
- [x] 필터·기존 메뉴 이동·모바일·오류 재시도 확인
- [x] 단위/독립/빌드/브라우저 검증 및 작업 보드 갱신
