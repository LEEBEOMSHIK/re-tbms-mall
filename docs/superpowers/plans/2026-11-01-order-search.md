# WB145 관리자 주문 상세 검색

- 요구 R111 / 담당 root(웹·문서·통합), backend(API·테스트), 별도 검증자.
- 목적: 주문번호·상품·수령인·전화, 주문일, 주문/결제/배송 상태로 주문을 찾는다. 고객 목록/상세 및 쓰기 기능은 변경하지 않는다.
- 계약: 관리자 GET sales-orders에 search_field(all/number/product/recipient/phone), q(100자), date_from/date_to(한국시간 포함일), payment_status, fulfillment_status 추가. 모든 조건 AND, 전체 검색 대상은 OR. 커서는 전체 적용 조건에 종속. 목록 개인정보 추가 없음.
- UI: 공통 입력/선택, 검색 명시 적용, 조건 초기화, 날짜 역전 안내, 검색 중 중복 방지, 필터 변경 시 첫 페이지. PC 다열/모바일 1열. 현재 페이지 건수만 표기.
- 수정: sales-orders API/테스트, 관리자 BFF, 공통 목록에 관리자 전용 검색 컴포넌트, CSS, admin-guide/captures, 디자인 시스템/계약/작업 보드.
- 수용/검증: 권한 유지, 필터 결합/문자 경계/날짜 경계/커서 계약 자동검증; 3100 합성자료 검색/초기화/빈결과/모바일/가이드 실제 확인과 캡처. 실제 주문/재고 쓰기 없음.
- 의존: WB143/144. PG 무관. 복구는 해당 코드 변경 되돌림, DB 마이그레이션 없음.
