# WB120 / R111 주문서 시안
- 목적: 확정된 판매·배송 정책을 실제 주문 전 검토할 수 있는 반응형 시안으로 표현한다. 담당 root, 독립 검토 별도.
- 사용자 승인: 정책 결정 후 주문서 시안 진행. 구현 선택: 기존 Next/쇼핑 셸 안의 /checkout/preview, 합성 상품·지역 시나리오만 사용. 실제 장바구니에 연결하면 주문 가능으로 오해할 수 있어 시안 전용 경로로 분리한다.
- 범위: 주문상품, 배송지 입력, 결제요약, 국내 일반지역/추가운임 미정지역 상태. PC 2열, 모바일 1열. 실제 주문·PG·재고예약·주소판별 API·개인정보 저장 없음.
- 파일: apps/web/src/app/checkout/preview/*, 디자인 시스템 고객 문서, 결정/요구/보드/검증 기록.
- 계약: 32,000원 합성 상품 1/2개로 배송비 경계를 시연, 할인후5만원 이상 무료. 지역 시나리오는 실제 우편번호 판별이 아님. 제주·도서산간 시나리오는 합계 미확정 및 진행 차단. 일반지역도 실제 결제 버튼 없음.
- 수용/검증: 타입/lint, PC/모바일 렌더, 1개35,000원/2개64,000원, 지역 제한 표시, 외부 쓰기 요청 없음. 시안 완료와 주문결제 구현 완료 구분.
- 가이드 영향 없음: 관리자 화면/업무 변경 없음. 디자인 시스템에 시안과 실기능 경계를 기록.
- 복구: 신규 경로 및 해당 문서 추가분 제거. DB/의존성 변경 없음.
