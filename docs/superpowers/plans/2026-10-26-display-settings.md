# 화면 설정 패널

WB22 / R35 / 2026-10-26

목적: 항상 노출된 글자크기 상단 바를 없애고 고객/관리자 헤더의44px 톱니바퀴 버튼에서 화면 설정을 연다. 로그인에도 설정 진입을 제공한다. 설정 내용은 기존 글자 크기이며 아직 요청하지 않은 다른 옵션은 추가하지 않는다. 브라우저 저장/확대 계약과 초기 복원은 유지한다.

UI 담당은 공통 설정 진입/대화상자와 헤더 연결, 조정 담당은 문서/보드/브라우저, 별도 검증자는 코드와 실행 결과를 확인한다. native dialog를 사용해 열릴 때 포커스, 모달 내 Tab, Escape/닫기 및 트리거 포커스 복귀를 보장한다. 320px 및 최대글자크기에서 패널이 화면 안에서 스크롤한다. 배경 클릭 닫기 지원. API/DB 변경 없음.

수용 기준: 상단 전용바 없음, 설정 버튼에서만 옵션 노출, 저장/복원/초기화 유지, 키보드/모바일/고객·관리자·로그인 진입 검증. 복구는 UI/문서만 되돌린다. 선행 WB21.
