# WB108 / R108 브랜드 소개 관리 구현 계획

사용자가 제안된 브랜드소개 관리/예시이미지 구성을 진행 승인. 구현 선택·계약은 docs/contracts/brand-about.md. 담당·파일소유권·수용조건 포함.
1. root: seed 콘텐츠/3개생성이미지 준비. 다른브랜드 디자인 복제없음. AI/전문분야를입는개성콘셉트.
2. backend: 추가형 SQLite draft/published/version 및 이미지안전처리, 인증/공개격리/충돌/경계/재시작테스트.
3. frontend: 타입검증/BFF, 동일브랜드View, 관리자상태/편집/미리보기분리, 업로드/SaveResult/실패보존/초안게시.
4. root: 사이트관리 nav/한글메뉴, 문서디자인시스템/요구/결정/보드. 통합API/웹/타입/lint 실행.
5. 별도검증자: 실제코드+테스트, root 브라우저 격리합성서버로 저장→미리보기→게시/공개초안격리/모바일focus/오류보존/직접URL인증 확인. 검증 안된사항 완료표시금지.
복구: 이번 소스와 추가 전용DB만 분리보존 후 복구. 기존미커밋파일/상품DB/카트/고객세션 보존. 자동push/배포없음.
