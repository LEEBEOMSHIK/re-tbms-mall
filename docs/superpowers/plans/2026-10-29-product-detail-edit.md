# WB95 상품 상세 편집 통합 계획

**Goal:** R100 — 상품 수정의 기본정보와 가격·할인·공개 설정을 상품 상세 한곳에서 편집한다.
**Architecture:** 기존 ProductForm과 PublicationEditor를 상세의 독립 구역으로 재사용한다. 기존 서버 API/버전 검증을 유지하고 구역별 저장 결과를 같은 화면에 표시한다.
**Tech Stack:** 기존 Next.js/React/TypeScript/FastAPI. 새 의존성 없음.
**Spec:** 사용자 2026-10-29 지시: 상품 수정에 있는 내용을 상품 상세에서 수정, 한곳에 모으기.

## 범위·계약·담당
- root 구현/문서/통합, 별도 검증자 실제 diff·실행 증거 검토.
- 수정: catalog/product-detail.tsx, catalog-manager.tsx, catalog-forms.tsx, publication-editor.tsx, catalog-list.tsx, product-price.tsx, 기존 두 edit 페이지, catalog.css 및 관련 문서.
- 기본정보 PUT products/{id}, 가격 PUT products/{id}/publication 계약 유지. 하나의 원자적 전체 저장을 가장하지 않고 구역별 저장 버튼을 명확히 표시한다.
- 기본정보 완료 시 부모 상품 요약을 서버 확정 응답으로 갱신. 가격 완료 시 확정 결과를 표시하며 상세 재조회 실패와 저장 실패를 구별한다. 다른 구역의 미저장 입력을 보존한다.
- 이전 /edit → 상세 #product-basic, /publication/edit → 상세 #product-pricing. 직접 URL 인증 유지.
- 상품 목록/신규 등록·재고 원장·옵션 업무 API는 그대로 유지. 한 상품의 옵션 요약과 이미지는 상세 문맥으로 남긴다. 전체 상품 목록/입출고 이력을 입력에 붙이지 않는다.
- 기존 '상세에 입력폼 없음' 규칙은 최신 사용자 지시로 상품 기본정보/가격에 한해 대체한다.
