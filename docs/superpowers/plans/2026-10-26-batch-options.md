# WB31 다중 색상·사이즈 일괄 등록

R41 / 2026-10-26. 목적은 반복 등록을 줄이고 저장 결과를 분명히 보여주는 것이다.

색상/사이즈 다중 선택 → 조합 미리보기(신규/기존 구분) → 서버 원자적 일괄 저장 → 실제 등록 결과 및 입고 동작을 제공한다. 기존 조합은 변경 없이 건너뛴다. API 담당 services/api, UI 담당 catalog forms/css, 조정 담당 lib/catalog.ts·BFF·문서, 독립 검증 담당 inventory_review로 분리한다.

POST /api/v1/admin/skus/batch 및 동일 Next BFF. 입력 {product_id,color_ids,size_ids,reorder_point}, 각 ID 배열1..50 중복불가, 전체 조합 최대200. 응답200 {created:SKU[],existing:SKU[]}, 요청 조합을 정확히 분할. 활성/종류/참조 서버 검증, 기존 옵션 불변, 신규 현재고0. 코드 충돌은409 및 전체 롤백. 기존 단일 API 유지. 재전송은 기존 조합으로 반환하며 중복 생성하지 않는다.

수용 기준: 다중선택/조합수/기존제외, 빠른추가 선택보존, 명확한 완료 제목·등록 조합·개수 및 포커스, 입고/목록/추가등록 링크, 오류 입력보존, 동시/경계/권한/원자성/재시도 검증, 모바일·키보드 확인. 테스트는 합성 DB와 모의 브라우저에서 실행한다. 실제 판매/게시/결제·재고입고 자동 수행은 범위 밖. 선행 WB30. 새 의존성/DB변경 없음. 복구는 이전 코드로 되돌리되 생성된 SKU는 재고 이력 보호 원칙을 유지한다.
