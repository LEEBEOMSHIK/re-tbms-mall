# WB77 / R87 중요한 값의 시각적 위계

- 목적: 현재 옵션/상품 재고 화면의 상태·수량·저장 변경값이 설명/코드보다 먼저 보이게 한다.
- 담당: root 공통표현/상세/옵션수정/문서, supplier_review 독립검증.
- 범위: 공통 KeyFacts, 옵션 입력 대상요약·완료전후, 상품상세 재고요약/표. API·계산·저장규칙 변경없음.
- 계약: 값과 라벨 분리, 변경전/후 명시, 서버확정값만 결과표시. 사용상태와 부족상태 의미색 분리, 색상만에 의존하지 않음.
- 수용: 핵심값 크기/굵기/배경/간격, 보조코드 낮은위계, 모바일1열, 다크/확대 대비·가로넘침, 저장완료초점 보존.
- 검증: lint/type, 브라우저 옵션수정/모의완료·상품상세 390/desktop 라이트·다크, 독립검토. 실제데이터쓰기없음.
- 복구: UI·CSS 변경복원, 데이터변경없음.
