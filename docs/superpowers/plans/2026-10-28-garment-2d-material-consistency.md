# WB83 2D·원단 표현 일치 보완 — 2026-10-28

## 목적과 범위
사용자가 3D 개선 후에도 2D 품질과 재질 식별이 부족하다고 지적했다. 내부 관리자 의류 시안 요구의 후속 수정이다. 현재 티셔츠 저장본은 면 저지·광택0 프리셋이며 실제 혼용률/중량/두께 데이터는 없다. 폴리에스터/스웨트는 면 자료 조정 표현임을 명시한다.

## 계약과 담당
- shared_flat_render: preview-3d.tsx, flat-projection.ts와 테스트. 동일 의류/재질의 고정 정사영 2D, 앞뒤 전환, 투명2048 PNG 캡처, 실제 옷 표면 확대.
- material_flat_ui: designer-pages.tsx, designer-editor.tsx, designer.css, 원단 정보. 편집/상세는 새 2D, 목록은 경량 배치 썸네일. 나염 좌표/영역/드래그를 프레임 폭과 높이에 대응한다.
- root: 문서·공동보드·통합 브라우저 검증. 독립 검증자는 변경 및 실행 결과를 확인한다.
- Preview3D presentation='flat', surface, onCaptureReady 콜백. flatFrame은 left/top/width/height, documentToFlat/flatToDocument 변환을 제공한다. 저장 문서/API/DB 계약 변경 없음.

## 수용 기준과 검증
1. 2D/3D의 형상·원단·나염이 일치하고 앞뒤 좌우를 보존한다.
2. 나염 선택·이동·영역 표시가 새 2D 위에서 정렬된다. 저장/조회 UX를 보존한다.
3. 현재 원단 이름/광택/스캔 또는 임시 표현 근거와 미등록 실제 사양을 표시한다.
4. PNG는 저장본 실제 형상과 원단을 포함한2048 RGBA이며 준비 실패 시 빈 이미지를 내보내지 않는다.
5. 좌표/기존 회귀 테스트, 타입/lint/build, PC/모바일 실제 화면, 독립 검토 결과를 기록한다. 미실행은 명시한다.
