# WB162 · 결제를 시작할 때 주문 생성과 재고 확보

R111. 고객이 확인한 주문 조건과 서버가 다시 계산한 상품·수량·금액·배송 조건이 같을 때 결제 대기 주문, 주문번호, 배송지와 품목 사본, SKU별 600초 확보를 한 트랜잭션에서 기록한다. 요청키 재시도와 같은 주문서의 중복 실행은 확보를 늘리지 않는다. PG 연결과 배송 가능 지역 판정은 서버 선행 조건이다.

재고 서비스 담당은 가용 수량, 멱등 처리와 만료를 구현하고, 결제 시작 담당은 인증·배송 판정과 수량 조회를 연결한다. 고객 화면 담당은 주문서 안내와 본인 주문 상세의 확보 상태를 맡는다. root는 웹 프록시·통합 검증·캡처·가이드와 작업 보드를 관리한다.

수용 기준은 마지막 한 개 경합, 다품목 전체 롤백, 서버 시각 600초 경계, 불확실 결제 보류, 고객 소유권, 기존 주문 호환, PG 미설정 시 무변경 및 고객 안내다. 합성 DB와 로컬 화면으로 검증한다. 기존 PG·결제 승인은 별도 결정이며 서비스를 실제 결제 가능 상태로 바꾸지 않는다.
