# WB50 / R60 전화번호 입력 제한

원인: WB49는 onChange가 모든 값을 상태에 저장하고 오류문구만 표시했다. 숫자 길이 검증은 저장 차단에만 사용되어 사용자의 입력 제한 기대를 충족하지 못했다.

- 범위: 대표전화·담당자 연락처 입력, 공통 전화 helper, 단위검증, 디자인/요구/보드. 서버의 기존 검증 유지, DB 변경 없음.
- 담당: supplier_ui apps/web 구현, supplier_review 독립검증, 조정 문서·Edge 통합.
- 계약: 일반 숫자 최대11, 선두+ 국제15, 허용문자/구분자. 입력 중 + 단독과 지우기는 허용하며 저장검증은 기존대로 유지한다. 초과·잘못된 입력은 이전값을 유지하고 거절 안내. 초과붙여넣기는 조용히 자르지 않는다. 거절 이후 기존값을 실수로 저장하지 않도록 유효 재편집 또는 명시적 해결 전 저장 차단.
- 기존데이터: 자동삭제/변환 없음. 제한초과 기존값도 지우며 교정 가능하고 미변경필드 생략 계약 유지.
- 수용/검증: 실제 타이핑12번째 차단, 하이픈포함11, +15/16, 붙여넣기거절 및 원값, 저장 요청0, 정상재입력 후 등록목록이동, 양쪽필드/모바일, 문자·+잘못된위치, 기존값교정. 단위/lint/type 및 독립 검증.
- 복구: 이번 전화입력 helper/폼 변경만 복원. 다른 작업 및 서버 데이터 보존.
