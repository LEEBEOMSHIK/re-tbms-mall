# WB45 사이트 다크 모드

R55. 사이트 설정 → 화면 및 접근성에 라이트/다크/시스템 테마를 제공한다. 기본 시스템, 브라우저 저장, 명시 선택은 OS보다 우선, 시스템 선택이면 OS 변경을 즉시 따른다. 글자 크기와 독립된 값이다. 새 의존성·API·DB 변경 없음.

inventory_ui: theme-control, theme helpers/tests, settings-content, root layout의 초기 적용. 조정: globals 색상 토큰/상태 배지 다크 토큰, 문서·브라우저. inventory_review: 독립 소스/테스트/lint/type/build.

html data-theme에는 해석된 light/dark를 적용한다. 초기 paint 전 저장값/OS를 적용하고 잘못된 값은 시스템으로 처리한다. 저장 차단 시 현재 탭 메모리에서 사용한다. 다른 탭 변경을 동기화한다. CSS 시스템 fallback도 제공한다. 상품 이미지 반전/필터는 금지한다. 공통 surface/text/action/error/success/focus 및 상태 배지 토큰을 사용한다.

수용 검증: OS 기본/전환, 명시 선택 우선, reload·route 유지, storage invalid/blocked/cross-tab, settings keyboard/mobile, 기존 font 설정 독립, 고객·관리자·입력·팝업 렌더링, 주요 텍스트 대비. 독립 웹 tests/lint/type/build. 실제 전체 접근성 인증을 주장하지 않는다. 복구는 테마 컴포넌트/초기 script/token override 제거(다른 작업 보존).
