# 브랜드 자료실 구현 계획

**Goal:** 관리자/공장 담당자가 기존 로고3종과 사용 기준을 조회·원본 다운로드한다.
**Architecture:** 기존 인증 layout 아래 두 URL이 동일 공통 자료실을 사용. 이미 고객사이트에 공개된 로고 원본을 재사용하고 복제하지 않는다. 공개 PNG를 비공개 자산이라고 표현하지 않는다. 쓰기/업로드/교체·상품별 버전 연결은 후속.
**Tech Stack:** Next.js/React, 기존 CSS 토큰. 새 의존성·DB/API 변경 없음.
**Spec:** 사용자 승인한 1차 범위(기존 로고3종+사용기준+다운로드), R108/WB159.

## 작업 명세
담당 root / 독립 검증 별도. 파일: brand-library.ts, brand-library.tsx/css, 관리자/공장 brand-library/page.tsx, site/page.tsx, admin-navigation.ts, factory-navigation.tsx, admin-guide.ts/captures 및 테스트/문서.
계약: 원본 경로·파일명·PNG 크기/해상도, 자료버전1/2026-11-02. 임의 인쇄 색상/크기 지정 없음. 두 화면 모두 기존 인증 필요. 원본은 이미 공개된 고객사이트 로고이며 다운로드 직접URL도 공개 유지.
수용: 3종 미리보기/다운로드 원본 동일, 용도·인쇄 미확정 안내, 양측 메뉴 진입·직접URL 인증, 모바일 넘침 없음, 실제 캡처·가이드 동기화.
복구: 신규 페이지/링크/공통 자료실만 되돌림. 기존 원본·브랜드 소개 DB 보존.
