# 사용자 글자 크기

WB21 / R35 / 2026-10-26. 사용자 요청을 글자 확대 기능으로 해석한다.

공통 루트에 기본/크게/더 크게(100/112.5/125%) 선택 도구를 둔다. 브라우저 localStorage에 표시 설정만 저장하고 잘못된 값/저장 차단은 기본값으로 안전하게 처리한다. 로그인 계정 동기화는 범위 밖이다. 기본 작은 안내문 14px, 보조문 15px, 본문16px을 rem 기반으로 구현해 사용자 브라우저 설정과 함께 확대한다. SSR 초기값은 기본이며 hydration 후 저장 설정을 복원한다. 고정 오버레이로 본문을 가리지 않는다.

조정 담당: 문서/보드/브라우저 통합. UI 담당: 공통 도구/루트/CSS. 독립 검증자: 코드·타입·lint 검증. 변경 계약은 텍스트 크기 토큰과 localStorage 키뿐이며 API/DB 변경 없음. 수용 기준은 즉시 확대, 새로고침/페이지 이동 유지, 초기화, 저장소 실패 시 동작, 320/390/1440px 레이아웃과 키보드 조작. 기존 필수 입력 흐름 회귀 검증. 복구는 UI/문서 변경만 되돌린다. 선행 WB20.
