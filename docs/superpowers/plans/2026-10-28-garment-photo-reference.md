# WB83 사진 기준 조직·두께·주름 구현 — 2026-10-28

- garment_shape_v2: garment-geometry.ts + cloth-shape.ts/테스트. 기존 의류에 원단별 정적 접힘과 두께를 반영하고 공동정점을 기준으로 법선을 재계산한다. XY/문서UV는 유지, z깊이로 부드러운 면접힘과 넓은 울굴곡을 구성한다. 실제 동적 물성 시뮬레이션으로 표현하지 않는다.
- sports_knit_material: fabric-material.ts + wool-knit.ts/테스트 + model/material-info. 울 부클레를 참고사진의 스토키네트 V자 코·실꼬임·코사이 음영을 가진 전용 조직으로 교체한다. 면의 촘촘한 원단 자료 유지. 생성자료를 실측스캔으로 표기하지 않는다.
- root: preview-3d.tsx·wool-fuzz.ts/테스트, 원단전환시형상갱신·실제모델위짧은잔털·출처/계획/보드/시각검증.
- 독립 검증: 실제 변경·실행결과와 참고사진 대비 전체/확대 캡처 확인. 단위테스트 통과를 실사품질 수용으로 대신하지 않는다.
