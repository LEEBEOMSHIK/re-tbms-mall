# WB67 / R79 시안 상세 중심 관리

- 목적: 상품상세 공장 요약은 이름 링크+상태, 시안 작업/내부 이미지는 시안 상세로 통합.
- 담당: root 요약·상세·문서, supplier_ui 이미지 조회/등록 경로, supplier_review 독립 검증.
- 파일 계약: ProductImages scope customer(default)/design. 상세 route saved_image 전달. design 업로드는 시안상세로 복귀. API/권한/공유/DB 변경 없음.
- 범위: 상품상세 공장 버튼 제거, 공장명 시안상세 링크(미배정도 상세 진입), 시안상세 명칭. 내부시안만 이동; 모델/의류이미지는 상품상세 유지.
- 수용: 이미지 섞임 없음, 저장/취소 올바른 복귀·실패 유지, 모바일/키보드, 기존 권한 경계 유지.
- 검증: 타입/lint, 이미지모의 브라우저 조회·업로드·복귀; 실제 데이터 쓰기 금지. 독립 코드 검토.
- 복구: 화면/이미지 scope 변경만 되돌림. 기존 이미지 레코드 이동/삭제 없음.
