# 고객 탐색 간소화·디자인 기준 분리 — WB89 / R97

**Goal:** 검색은 항상 보이고 상세 설정은 기본 접힌 고객 쇼핑 UI로 변경하며 고객/관리자 디자인 기준을 분리한다.
**Architecture:** 기존 공개 데이터와 URL 필터 계약을 유지하고 고객 컴포넌트/CSS 범위에서만 탐색 구조와 시각 위계를 변경한다. 공통 토큰/접근성은 공유한다.
**Tech Stack:** 기존 Next.js·React·CSS. DB/API/의존성 변경 없음.
**Spec:** 사용자 최신 지시 / docs/design-system-customer.md / docs/design-system-admin.md.

## 소유권
- public_catalog_web: 고객 목록/홈/상세/셸의 컴포넌트·CSS와 필요한 테스트.
- public_catalog_review: 독립 기능/시각검증, docs/reviews/customer-design.md.
- root: 디자인 기준·요구/결정·작업 보드·통합검증. 기존 미커밋과 관리자/공장 업무 화면 보존.
