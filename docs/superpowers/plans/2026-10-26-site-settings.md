# 사이트 설정 확장 구조

WB23 / R35 / 2026-10-26

사용자 요구: 톱니바퀴는 사이트 설정이며 글자 크기는 여러 설정 중 하나다. 제목만 바꾸지 않고 공통 설정 셸과 개별 설정 구현을 분리한다. 현재 사이트 설정 > 화면 및 접근성 > 글자 크기 계층을 구현한다. 향후 테마·동작 효과·알림·언어 등은 후보이며 기능/저장 범위/권한/계약 결정 전 비활성 메뉴나 가짜 토글을 추가하지 않는다.

UI 담당: site-settings 공통 dialog/SettingsSection과 text-size 개별 설정 분리, 진입점 이름/모바일. 조정 담당: 확장 설계 문서/보드/브라우저. 독립 검증자: 소스·타입·lint. 기존 저장키와 초기복원, 모달 포커스/닫기 유지. API/DB 변경 없음.

수용 기준: 사이트 설정 제목, 화면 및 접근성 그룹, 글자 크기 하위 항목; 다른 설정을 추가해도 글자 컴포넌트에 의존하지 않는 셸; 현재 기능과 후보 구분;320px 최대확대 및 키보드/저장 회귀. 복구는 UI·문서 변경만 되돌린다. 선행 WB22.
