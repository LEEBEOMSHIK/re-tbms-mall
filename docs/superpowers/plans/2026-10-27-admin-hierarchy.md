# WB78 / R88 관리자 전체 핵심값 위계

- 목적/범위: 구현된 모든 관리자 routefamily를 조사하고 핵심값의 위계를 WB77 공통기준으로 통일. 업무·금액·상태를 새로 생성하거나 API/계산을 바꾸지 않는다.
- 담당/파일: root 공통 KeyFacts/상태표현·dashboard·merchandising·workboard·문서, supplier_ui catalog/**, supplier_api factories/** 및 공유 product-progress, supplier_review 독립 전체검증. 공통파일 담당 root만 수정.
- 점검대상: 대시보드, 상품목록/등록/수정/상세, 옵션등록/수정, 재고현황/이력/입출고조정, 카테고리/색상사이즈기준정보 목록/등록/수정, 공급처 목록/등록/수정, 이미지목록/등록, 공장 시안/계정/제작요청/배정, 진열목록/등록/수정/완료, 작업보드. 로그인/원문출력은 업무수치 적용대상 아님.
- 공통계약: KeyFacts 라벨/값/previous/note. 요약은 2~3개 핵심값, 행은 이름·상태·수량만 강조. 관리코드/버전/설명은 보조. 링크형 요약은 링크 의미/키보드 유지. 카드는 비대화형이면 클릭으로 오인시키지 않는다.
- 저장: 기존 확정값·실패입력·후속경로·모바일초점 유지. 입력중 값은 저장결과로 표현하지 않고 입력요약으로 명시. 상태색과 텍스트 병행. 사용여부·판매·재고·시안 상태 혼합금지.
- 미정/제약: 대시보드/진열은 샘플 표시 유지; 실제가격/결제없는 화면에 금액추가 금지. 정적공유부품으로 공장포털에도 표현 영향가능, 권한변경없음.
- 검증: 변경/유지 사유별 family표를 리뷰문서에 기록. 담당별 라이트/다크·desktop/390·24px 브라우저, 모의쓰기완료/실패, 별도검증 lint/type/webtests. 전체URL을 브라우저로 열었다고 추정하지 않음, 검증 URL명시. 실제데이터쓰기 금지.
- 수용: 핵심값 식별, 모바일줄바꿈/넘침없음·표자체스크롤, 목록입력분리/페이지네이션유지, 문서일관성, 독립검증.
- 복구: UI/CSS 변경복원, DB/API변경 없음.
