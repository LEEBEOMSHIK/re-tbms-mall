# 주문·결제 연동 후보 비교 (결정 전)
사용자 요청: 바로 구매→주문서→실제 주문·결제를 별도 설계 후 구현. PG 미정, 후보 비교부터 진행.

| 방식 | 적합한 상황 | 고려사항 |
|---|---|---|
| 토스페이먼츠 직접 연동 | 단일 국내 쇼핑몰, 단일 PG 시작 | 계약/정산/연동 창구 단순화. 다른 PG 추가시 별도 구현 필요 |
| 포트원 V2 + 선정 PG | 복수 PG, 향후 교체/확장 필요 | 통합 API 활용. 포트원과 실제 PG 계약/비용 구조 구분 필요 |

구현자 추천은 토스 직접 연동이며 사용자 승인 전이다. 정확한 결제 수수료/가입비/정산 조건은 사업자/결제수단별 견적으로 결정한다. 공용 테스트와 실제 계약 키/운영 심사 범위를 구분한다.

공식 근거 (2026-10-30 확인):
- https://docs.tosspayments.com/guides/v2/get-started/environment
- https://docs.tosspayments.com/guides/v2/deploy-checklist
- https://developers.portone.io/opi/ko/readme?v=v2
- https://developers.portone.io/opi/ko/console/guide/reg?v=v2
- https://www.portone.io/pricing

선정 후 설계할 항목: 바로구매는 현재 SKU/수량만 주문서로 전달하고 기존 카트와 구분. 서버 견적/가격·재고 재검증, 주문/품목/주소/정책 스냅샷, 결제요청/승인/조회/웹훅/중복처리, 취소/환불·재고복구, 관리자 주문처리/고객 주문조회. 성공 redirect만으로 결제 완료 처리하지 않는다.
필요한 사용자 결정: PG, 판매·배송 형태, 배송비/반품비, 재고확보 시점과 만료, 취소·부분환불 범위, 운영 사업자/도메인. 아직 운영 규칙으로 확정하지 않는다.
결제 개발은 테스트 환경부터, 실제 돈이 이동하는 검증/계약/배포는 별도 승인. 현재 문서는 후보 비교이며 승인된 전체 설계가 아니다.

## 사용자 결정 및 계약 조건 비교 (2026-10-30)
사용자는 PG를 선택하지 않고 업체 계약 조건을 먼저 비교하기로 결정했다. 앞선 토스 추천은 구현자 제안일 뿐 채택되지 않았다. 가입/견적 요청 발송/계약/실결제는 실행하지 않음.

공개 공시 기준, 확정 견적 아님:
- 토스 직접: 일반 카드3.4%(VAT별도), 가입비220,000원/연관리비110,000원 표기(계약형태별 상이). 평균5일 이내 정산 안내는 보장된 계약 D+n이 아님. 정산한도1,000만원까지 보증보험 면제 혜택 공시, 실제 적용조건 확인 필요. https://www.tosspayments.com/about/fee
- 포트원 경유 공시(VAT별도): 토스 가입비20만원/일반카드3.20%/영세1.65%; NHN KCP 가입비무료/일반3.20%/영세1.72%; KG이니시스 가입비무료/일반3.20%/영세1.90%. 직계약 요율로 일반화하지 않음. https://help.portone.io/category/pricing
- 포트원 플랫폼은 PG수수료와 별도. 월순거래액5천만원미만 무료, 5천만원~1억원미만 월10만원, 1억~5억원미만 월30만원, 5억원이상 월50만원(VAT별도, 월결제 기준). https://www.portone.io/pricing

비교 견적에 반드시 받을 항목: 카드/간편결제별 실적용요율과 VAT, 가입/연관리/플랫폼/보증보험 총비용, 정산 D+n과 영업일/보류/한도, 주문제작·선주문 배송기간 허용, 전액/부분취소시 원수수료 반환 및 추가환불비용, 최소약정/해지/프로모션 종료 조건. KCP/이니시스 정산·보증·연관리비는 이번 공식 자료로 확정하지 못함.
월카드매출1천만원 가정시3.4%와3.2% 차이는 월2만원(VAT전)으로, 가입·연회비·플랫폼비를 함께 비교해야 한다. 매출등급과 예상매출은 사용자 정보 미확인.
