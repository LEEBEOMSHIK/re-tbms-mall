# 관리자·공장 업무 디자인 시스템

적용: `/admin`, `/factory`의 로그인·대시보드·목록·등록·수정·상세. 공통 토큰과 저장 규칙은 [공통 디자인 시스템](design-system.md)에 정의되어 있으며 본 문서는 업무 화면 적용 기준이다. 고객 쇼핑 화면은 [고객 디자인 시스템](design-system-customer.md)을 따른다.

## 목적과 정보 위계
정확한 업무 판단과 처리 속도를 우선한다. 상품명/대상·현재 상태·수량·처리 기한을 먼저 보여주고 기술 코드·긴 메모·변경 이력은 보조 정보로 묶는다. 화면별 핵심값은2~3개를 선정해 굵기·단위·의미 색상으로 강조한다. 재고 부족은 빨강+문구, 양호는 초록+문구다.

## 업무 화면 구성
- 대시보드는 실제 집계·현재 업무·정확한 상세 링크를 제공한다. 샘플과 실제 데이터는 명확히 구분한다.
- 목록·등록·수정은 별도 URL이다. 목록은 검색/필터·요약·페이지당 개수·페이지 이동을 지원하며 필터 변경시 첫 페이지로 이동한다.
- 표의 텍스트·수량·행 버튼은 세로 중앙 정렬한다. 코드/설명 때문에 중요한 상태와 동작이 밀리지 않도록 한다.
- 항목이 많은 폼은 본문 폭을 활용하고 연관 필드를 구역으로 묶는다. 모바일은1열이다. 필수값은 별표와 접근성 정보를 제공한다.
- 주요 작업은 목록 위나 상세의 명확한 동작 영역에 둔다. 긴 목록 아래까지 내려가야만 등록할 수 있게 하지 않는다.
- 고객용 이미지 중심 배치와 장식 효과를 업무 폼·재고 표에 그대로 적용하지 않는다.

## 저장·권한
공통 디자인 시스템의 서버 확정 결과·실패 입력 보존·중복 저장 차단·충돌 재조회 규칙을 따른다. 저장 완료 후 업무 문맥에 맞는 상세/목록으로 복귀하고 결과를 명확히 표시한다. 별도 완료 화면은 사용자 승인된 흐름에만 유지한다. 공장 역할은 본인 범위만 제공하고 실제 권한은 서버에서 검증한다.

## 공통 컴포넌트와 검증
KeyFacts·StatusBadge·FormLabel·FormSelect·SaveResult 등 기존 공통 컴포넌트를 우선 사용한다. 라운드·간격·입력 높이·아이콘 크기는 공통 토큰을 사용한다. 고객 화면 전용 CSS가 관리자/공장 화면에 누출되지 않는지 확인한다. 저장/오류/직접URL인증·키보드·모바일·다크·확대 검증과 독립 검증 근거를 남긴다.

## 가격·리뷰 관리 — WB91
상품 상세에서 가격과 가격/이력 관리 경로를 명확히 표시한다. 리뷰 목록은 상품·별점·공개상태를 우선하고 긴 본문/이력은 별도 수정 화면에서 확인한다. 숨김/복원·답변 저장에는 사유를 기록하고 저장 후 목록으로 복귀해 일회성 결과를 표시한다. 실패 입력 보존·버전 충돌 재조회·고객 삭제 리뷰 변경 금지를 적용한다. 리뷰 평균을 직접 수정하는 입력은 만들지 않는다.

## 할인 가격 설정 — WB92
기본 판매가격과 할인 판매가격 입력을 구분하고, 할인 적용은 토글로 명시한다. 입력 옆 고객표시 미리보기에 기본가·할인율·최종 판매가격을 보여준다. 서버 검증 전 미리보기는 저장결과가 아니다. 저장 후 상품상세에서 확정 가격을 확인하고 이력은 별도화면에 기본/할인/최종값을 표시한다. 오류/충돌 시 입력은 보존한다.
