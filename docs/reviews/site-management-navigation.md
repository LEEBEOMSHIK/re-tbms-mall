# WB174 사이트 관리에서 홈 진열로 이동

R23 후속. 사이트 관리가 홈 진열 목록·등록·수정의 상위 메뉴다. 기존 사이트 관리 URL과 각 업무 URL을 사용한다. 브랜드 소개와 공장용 로고 자료는 ‘브랜드 콘텐츠’로, 관리자 메뉴 구성은 ‘관리자 설정’으로 구분한다.

수정 범위는 관리자 메뉴 레지스트리와 이전 저장 설정 호환 처리, 사이트 관리 화면, 진열 목록 및 편집 화면, 사용 가이드(start, merchandising)와 디자인 시스템이다. 진열 구성의 저장·게시 계약은 그대로 사용한다. 검증에는 로컬 메뉴 조회, 저장된 설정 호환 테스트, 사이트 관리의 네 링크와 진열 하위 화면의 현재 위치, PC와 모바일 캡처를 사용한다.

3100 메뉴 API는 인증 조회 200, 11개이며 홈 진열 단독 항목은 없다. 기존 12개 구성은 해당 항목만 제외하고 공유 설정 원문·버전·숨김·순서를 보존한다. 메뉴 API 테스트 35개 및 전체 웹 테스트 235개, 타입 검사와 대상 lint 통과. PC 1440·모바일 390에서 사이트 관리의 네 경로와 진열 하위의 현재 위치, 이미지 로딩 및 가로 넘침을 확인했다. 등록/수정은 상품명·색상 검색과 선택 순서, 모의 저장 거절 후 입력 유지 및 성공 후 완료 제목 포커스·목록 복귀를 검증했다. 실제 진열 구성 쓰기 0건. 가이드 start:1, merchandising:0/1 교체. 복구는 이전 표시·메뉴 계약 및 UI 소스를 함께 되돌리는 방식으로 처리한다.
