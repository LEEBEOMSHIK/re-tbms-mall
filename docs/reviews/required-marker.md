# 필수 입력 기호 검증

2026-10-26 / WB20 / R34
계획: docs/superpowers/plans/2026-10-26-required-marker.md

조정 담당이 FormLabel의 필수 텍스트를 별표로 변경하고 FormRequiredHint를 상품·옵션·재고·카테고리 폼에 각각 한 번 적용했다. 디자인 시스템에 공통 규칙을 반영했다. inventory_review는 별표의 aria-hidden, 기존 required/aria-required 및 조건부 필수 계약, 안내 배치와 문서 일치를 독립 검토했다.

Edge 스모크 전체 재실행 exit 0: 별표 표시와 안내 1회, 필수값 누락 차단/첫 오류 포커스, 옵션 선택/키보드/비활성, 기존 상품 수정, 320/390/1440px 경계 확인. 데스크톱 캡처에서 별표와 공통 안내를 직접 확인했다. 저장 요청은 모의 응답으로 처리했다. 표시 변경에 한정되므로 백엔드/프로덕션 빌드를 반복하지 않았다. 복구는 이번 UI와 문서 변경만 되돌린다.

독립 타입 검사도 exit 0으로 통과했다. 작업 보드는 WB20 완료로 갱신했다.
