# WB231 주문 상세 반품·교환 진입 개선

- 요구 R111, 담당 root / 독립 검증자. 목적: 고객 주문 상세에서 신청 버튼을 쉽게 찾고 전체 내역과 혼동하지 않게 한다.
- 범위: 고객 주문 상세 CTA와 주문별 접수 요약. 전체 내역은 주문 목록에 유지, 관리자 화면·API 계약·데이터 쓰기 변경 없음.
- 설계: 옅은 강조면에 간단한 설명과 아이콘+퍼플 주요 CTA를 배치한다. 기존 접수는 하단 `이 주문의 신청 현황`에 상품·유형·수량·상태를 표시하고 해당 상세로 연결한다. 접수 0건이면 현황은 숨긴다. 조회 오류는 빈 내역으로 가장하지 않고 재조회 제공. 목록 20건 이후는 해당 주문 내역으로 이어진다.
- 파일: components/customer-order-claims.tsx, sales-orders.tsx/css, 디자인 시스템, 가이드, 작업 보드.
- 계약: GET /api/customer/claims?order_id=UUID. 소유권은 서버가 검사. 결제 성공+confirmed/closed+배송 시작 상태에서 신청 CTA 표시. 신청 가능 수량의 최종 검증은 기존 접수 화면·서버를 따른다.
- 수용 기준: 중복 내역 버튼 제거, 주요 CTA 명확, PC/모바일 줄바꿈·간격·포커스, 접수 요약/빈 상태/실패/세션 변경, 기존 주문·재고 미변경.
- RED: 실제3100 주문 상세에서 `상품 반품·교환 신청` 영역 0개, 동일한 외곽선 내역/신청 링크 2개를 확인.
- 검증: 완료(후속 검증 결과 참조). 가이드 claims/sales-orders 원문 동기화, 관리자 캡처는 관리자 UI 변경 없어 유지.
