## 남은 검증과 제한

구현 및 위 검증은 완료했으나 수용 기준 전체 완료로 선언하지 않는다. 강제 WebGL context loss/복구, 20레이어 GPU 부하·지연/FPS 정량 측정, 실제 두 브라우저 탭 충돌 후 사본 저장 전 과정, 밝은 테마·큰글씨·스크린리더 실기 검증은 미실행이다. 동시 저장/사본/상한은 서버·단위 테스트로 검증했으며 실제 브라우저 검증과 구분한다. 조정 담당 후속 검증 대상이다.

3D는 기본 절차형 메쉬이며 실제 패턴·봉제·주름·처짐·생산 발색을 재현하지 않는다. 다른 실제 의류 모델/장식 방식/3D 직접 편집은 확장 경계만 마련했다. 제조용 CAD/인쇄 분판 출력은 없다.
