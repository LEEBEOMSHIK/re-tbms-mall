# 글자 크기 설정 검증

2026-10-26 / WB21 / R35
계획: docs/superpowers/plans/2026-10-26-text-size.md

inventory_ui가 루트 공통 TextSizeControl, CSS, rem 토큰과 고정 글자 크기 정리, 고객 헤더 줄바꿈을 구현했다. 조정 담당은 문서·브라우저 통합을 담당하고 inventory_review는 독립 검증했다. API·DB·외부 의존성 변경은 없다.

조정 담당 Edge 스모크 exit 0: 기본 본문16px → 크게18px → 더 크게20px, 선택 상태, 새로고침/다른 페이지 유지, 기본 초기화, 키보드 Enter, 저장 차단에도 현재 화면 확대를 확인했다. 별도 스모크 exit 0으로 잘못된 저장값의 기본 복귀, 같은 브라우저 다른 탭의 설정 변경/초기화 전파, 기본 선택 시 저장키 제거를 검증했다.

최대 크기에서 고객 홈·관리자 홈·상품 등록·분류 관리 각각320/390/1440px 가로 넘침을 확인했다. 상품 등록 필수값 누락 포커스와320px 옵션 목록의 화면 경계도 통과했다. 320px 폼과390px 상단 설정 화면 캡처를 직접 검토했다. 실제 상품 저장은 하지 않았다. 스크립트는 로컬 .local/text-size-smoke.cjs, .local/text-size-storage.cjs에 있다.

설정은 브라우저 단위이며 계정/기기 간 동기화가 아니다. SSR 기본 크기 이후 저장 설정을 복원하므로 초기 크기 변화가 가능하다. 모든 브라우저·보조기기·브라우저200% 확대 인증을 주장하지 않는다. 복구는 이번 UI·문서 변경만 되돌린다. 기존 저장 키는 무시 가능하며 서버 데이터 복구는 필요 없다.

독립 검증자는 소스 검토 및 웹 테스트33개·lint·타입 검사·프로덕션 빌드 모두 exit 0을 확인했다. 조정 담당의 작업 보드 파서5개도 통과했다. 브라우저 검증은 위에 기재한 조정 담당의 실제 실행 결과다. WB21 완료로 갱신했다. 다음 작업 제안은 기존 WB13(대시보드 실제 재고 연결)을 유지하며 이번 요청으로 추가 실행하지 않았다.
