## 제한과 유지관리
이미지는 합성 예시이며 운영 데이터가 아니다. 모든 단계에 이미지가 있는 것은 아니며 10개 업무의 주요 진입/입력/완료 단계를 19개 연결로 제공한다. 전체 브라우저 접근성 감사·운영 빌드 배포는 수행하지 않았다. 캡처와 표식은 자동 생성 갱신이 아니므로 UI 변경 작업에서 함께 재검토한다. 실제 결제/운영 관리자 계정 정책 등 기존 미정은 유지.
