# 자동 슬라이드·푸터·작업 보드 검증

날짜: 2026-10-25
계획: ../superpowers/plans/2026-10-25-carousel-footer-workboard.md

## 역할

- carousel: 독립 상품 캐러셀 및 카드 연결, CSS.
- footer_board: 공통 푸터·정책 안내·작업 보드와 단일 JSON 원본.
- carousel_board_review: 읽기 전용 독립 소스 검토, 웹 검증 명령 실행.
- 조정 담당: 요구/결정/디자인 문서, 관리자 이동 링크, 실제 브라우저 통합 확인 및 상태 갱신.

## 검증 결과

독립 실행: 웹 테스트 10/10, lint, typecheck, production build 모두 통과. 작업 보드 및 정책 4개 페이지 생성 확인. 소스 검토 차단 사항 없음.

Edge 브라우저에서 API 응답만 일시적으로 12개 상품 섹션으로 대체하여 자동 전환을 검증했다. 실제 저장 진열은 변경하지 않았다. 자동 넘김, hover 정지, 수동 이동/끝에서 처음 복귀, 상품 상세 열기/닫기, 모바일 가로 넘침 없음, reduced-motion 자동 재생 중지, 넘치지 않는 섹션의 컨트롤 숨김과 JavaScript 오류 없음을 확인했다.

스냅 여백을 scroll-padding-inline:3px로 맞췄다. 실제 desktop 좌표 0→1344→2688→0을 확인했다. 화면 크기 및 스크롤바에 따라 페이지 수가 달라질 수 있으므로 끝점 검증은 실제 scrollWidth-clientWidth를 기준으로 한다.

푸터·보드 브라우저 최종 검사 통과: 모든 하단 메뉴/정책 링크 200, 없는 정책 404, 보드 9개 카드와 읽기 전용 설명, 320·390·1440px 가로 넘침 없음, 관리자 상호 이동 확인. 고객 메뉴에 작업 보드 링크 없음.

## 제한

회사 정보는 미등록, 정책은 정식 문서가 아닌 준비 안내다. 작업 보드는 apps/web/src/data/workboard.json의 읽기 전용 화면으로 요청 및 검증 결과를 대화에서 반영한다. 자동 에이전트 상태 감시나 웹 편집, 운영용 접근 보호는 구현하지 않았다. 다음 작업 제안과 결제·시안 등의 미정 사항은 완료로 표시하지 않는다. 로컬 Docker 구성 및 백엔드 변경 없음.
