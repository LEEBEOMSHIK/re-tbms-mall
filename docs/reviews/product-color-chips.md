담당 root, 의존 기존 옵션명. 수정 파일: color-chip.ts, ui/color-chip.tsx/css, product-option-preview.tsx, shop-products/product-carousel, catalog의 product-detail/catalog-list/catalog-forms/option-value-manager/reorder-point-editor, admin-guide 및 디자인 문서·보드. 수용기준: 옵션 중복제거, 미지정 안전처리, 관리자 이름병기, 기존 동작 유지, PC/mobile 시각 확인. 검증은 타입/lint/대표색 경계/가이드 테스트 및 실제 캡처. 가이드 영향 ID catalog/inventory, 캡처와 표식 재확인 필요. 복구: 이번 표현 변경만 되돌리며 저장 데이터는 변경하지 않음.

## 검증 결과
- TypeScript 통과. 초기 import 누락을 독립 검토/타입검사에서 발견하여 수정하고 재검증 통과. 변경 파일 ESLint(누락 수정 후 product-detail/ColorChip 재실행) 통과. 대표색·가이드 링크/자산/보드 테스트10 통과.
- 독립 검토에서 이름 병기칩의 중복 읽기를 발견하여 장식아이콘 aria-hidden 적용, 재검토 차단 없음.
- 실제 고객 상품카드에서 빨강칩·스몰/미디움 확인. 관리자 색상 기준정보에서 빨강/파랑·미지정 구분 확인. 데이터 저장/재고 변경 없이 조회. 캡처 `.local/wb137-product-card.png`, `.local/wb137-admin-colors.png`.
- 가이드 catalog/inventory 문구·날짜 갱신, /admin/guide에서 catalog 단계 새 문구 표시 확인. 기존 inventory-list/form/catalog-options 이미지를 시각검토: 이번 칩이 들어간 표/선택후 요약은 해당 캡처 영역 밖이므로 기존 클릭대상/표식 좌표 변경 없음, 이미지 교체 불필요.
- 모바일 viewport 재설정을 시도했으나 실제 innerWidth1280으로 확인되어 모바일 검증 완료로 기록하지 않음. 모바일 전용 캡처는 미실행. API/DB 변경 없음으로 전체 API 회귀는 생략. root PC 통합 확인, 모바일 추가 시각 검증은 후속.
- 정확한 사용자 정의 색상값을 등록하는 기능은 이번 범위에 포함하지 않는다. 현재 칩은 색상명 대표색이며 알 수 없는 색상은 임의 추정하지 않는다.

## 사용자 시각 피드백 후속
18px 이중링/안쪽 흰 테두리가 버튼처럼 보인다는 피드백에 따라16px 단색 원형·칩간격10px로 변경. 그림자와 내부링 없음. 테두리는 테마 텍스트색18%의1px로 밝은/어두운 배경에서 경계만 제공한다. 독립 검토에서 다크 배경 검정칩 경계 위험을 발견해 고정 검정 테두리를 테마 기반으로 보완. PC 실제 CSS16px/box-shadow none 및 카드 캡처 .local/wb137-flat-swatches.png 확인. 관리자도 같은 컴포넌트 사용, 가이드 클릭영역 변화 없음.

## 최신 사용자 방향: 컴팩트 한 줄
두 행/색상명 병기로 카드가 길어진다는 사용자 피드백에 따라 라벨·일반 색상명 제거, 12px 칩과22px 사이즈 배지 한 줄로 정리. 알려진 사이즈만 알파벳으로 표시(S/M 등), 원데이터/API/관리자명은 변경하지 않음. PC 실제 옵션영역22px, 샘플 카드592.86px→536.86px(56px 감소), S/M 표시 확인. .local/wb137-compact-options.png. 변경파일 ESLint 통과. 관리자 가이드/기존 캡처 추가 영향 없음.
