# WB82 / R91 공장 테스트 로그인 검증

## 범위와 결과

로컬 전용 테스트 버튼은 기존 공장 인증을 사용한다. 샘플 공장·담당 상품·옵션·공유/내부 시안·제작 요청은 전용 seed로 준비하며 기존 계정/자료를 초기화하지 않는다. 브라우저로 비밀번호/상위 토큰을 전달하지 않는다. 내부 관리자↔공장 로그인 시 반대 역할 Next 세션을 폐기한다.

발견·수정한 화면 문제:
- 제작 요청 상세의 쓰기 버튼과 전체 이력 혼합 → 별도 상태 변경 URL, SaveResult와 상세 복귀.
- 실패 상태에서 최신 조회 후 복구가 명확하지 않음 → 재조회 전 재저장 차단·확정 버전/대상 검증.
- 공장 상품 진행 상태 명칭/반복 코드 열 → 시안 진행 상태·상품명 아래 코드 4열.
- 공장 화면에서 사이트 설정 접근 누락 → 헤더 설정 추가.
- 시안 이미지 조회의 callback 의존성 불안정 → 안정된 callback으로 불필요 재조회 방지.

## 권한/사용 범위

공장: 배정 상품·옵션 식별값·명시 공유 시안 조회, 시안 진행 상태/메모 변경, 본인 제작 요청 조회·접수→제작중→완료 처리. 내부 재고 수량·다른 공장·미공유 시안·상품/계정/공급처 관리·작업보드 등 내부 관리자 API는 허용하지 않는다. 시안 이미지 등록·공장 배정·공유 설정은 내부 관리자 권한을 유지한다.

운영 테스트 진입은 서버에서 거부하고 버튼도 숨긴다. 일반 공장 계정 운영 인증/권한은 변경하지 않았다. 운영 배포/실제 공장 메시지/결제 연동은 수행하지 않았다.
