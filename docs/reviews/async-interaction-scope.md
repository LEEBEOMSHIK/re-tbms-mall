# WB200 · 비동기 상태가 관계없는 조작을 잠그는 문제 점검

- 요구: R105, R107, R108 / 요청일·검증일: 2026-11-05
- 목적: 부분 갱신 때 버튼·탐색을 불필요하게 잠그지 않고 데이터 정합성을 유지한다.
- 담당: 구현·통합 root, 독립 검증 hold_ui.
- 선행: WB198, WB199. PG·택배사 결정에 의존하지 않는다.
- 계약: URL·API·DB·권한·가격·재고 규칙은 유지. 화면 요청 시간 제한 20초와 기존 결과 불확실 처리 연결만 변경.
- 수용 기준: 영향 없는 조작 유지, 마지막 검색 우선, 이전 재고 표시, 실제 쓰기 경합 방지, PC·모바일 합성 지연/실패 검증.

## 점검과 변경

busy/loading/pending/disabled 사용처를 기준으로 관련 TSX 38개 파일을 조사했다. 전체 화면의 모든 동작을 실행했다는 의미는 아니다.

| 영역 | 결과 |
|---|---|
| 상품 상세 바로 구매 | 장바구니 저장·충돌·결과 불확실과 분리. 현재 옵션/수량 검증 유지 |
| 고객·관리자 주문 검색 | 조회 중 검색·초기화 유지. 기존 요청 취소와 최신 조건만 반영. 20초 초과 시 한국어 재조회 안내 |
| 배송 정보 | 삭제 창 닫기/다른 대상 확인 허용. 실제 삭제 확정은 진행 요청·충돌·결과 불확실 상태에서 보호. 완료된 대상과 열린 대상 일치 때만 닫음 |
| 관리자 재고 요약 | 조회 중 성공 카드·링크·기준시각 유지, 실패 때 명시, 401 때 데이터 제거. 중복 새로 조회는 한 요청 |
| 고객 공통 요청 | 20초 제한. 쓰기는 unknown으로 보존하며 자동 재전송 금지 |
| 장바구니 | WB198/199의 계산 영역 피드백·최신 버전 결제 진입 유지 |
| 기타 저장·게시·업로드·취소·인증 | 실제 문서/재고/세션/버전 공유에 필요한 잠금 유지. 무조건 disabled 제거하지 않음 |

주요 수정 파일: `customer-add-to-cart.tsx`, `customer-order-search.tsx`, `admin-order-search.tsx`, `sales-orders.tsx`, `customer-account.tsx`, `lib/customer-shopping.ts`, `app/admin/(protected)/inventory-overview.tsx`, `dashboard.css`, `tests/customer-shopping.test.ts` (모두 apps/web/src 기준, tests 제외).

## 검증 근거

- 공통 요청 테스트: 시간 제한 추가 전 6 통과/1 실패 확인 후 7 통과. 전송 횟수·본문 보존·unknown 결과 검사.
- 집중 자동 검증 17개 통과, 웹 전체 `npm test` 248개 통과. 로그 `.local/wb200-web-tests.log`.
- 독립 실제 Chrome 1440px/390px: 바로 구매 busy/conflict/unknown, 삭제 A 진행 중 B 확인/닫기와 A 완료 후 B 유지, 불확실 결과에서 새 삭제 금지, 고객/관리자 검색 지연 응답 역전·초기화 통과.
- 관리자 재고: 지연·503 때 합성 재고 123 유지, 링크 활성, 연속 조회 한 요청, 401 때 카드 제거 통과. 실제 20초 무응답은 unknown 전환 확인.
- 조정 담당이 독립 브라우저 스크립트를 재실행해 PC·모바일 시나리오 통과. 최초 조정용 통합 fixture의 주소록 인증 준비 실패는 성공으로 산입하지 않고 검증된 별도 fixture로 재검증했다.
- 캡처: `.local/wb200-orders-1440.png`, `wb200-orders-390.png`, `wb200-address-390.png`, `wb200-inventory-1440.png`, `wb200-admin-search-390.png`, `wb200-search-timeout.png`.
- 합성 응답을 로컬 실제 앱에 주입한 지연/실패 UI 검증이다. 실제 고객 데이터 변경·PG·운영 성능 검증은 수행하지 않았다.

## 가이드·문서·복구

가이드 `start`, `sales-orders`에 재조회/재검색 동작 반영. `sales-orders:1` 실제 로컬 합성 화면을 다시 캡처하고 상세 필터의 좌표를 재산출했다. 독립 검증자가 캡처와 표식의 시각적 일치를 확인했다. `start:1`은 사이드바 설명으로 이번 카드 변경 영향이 없다. 고객 화면은 관리자 업무 절차 영향 없음. 디자인 시스템에 부분 작업 상태 범위 규칙, 검증 템플릿에 경합/지연 항목 추가.

최종 추가 검증: 타입 검사·수정 파일 ESLint 통과, 가이드/보드 자동 테스트 9개 통과. 실제 21초 지연 조건에서 한국어 시간 초과 안내와 조회 버튼 활성 확인(`.local/wb200-guide.log`, 종료 0). 독립 검증자의 최종 소스·문서·캡처 재검토에서 미해결 기능 문제 없음. 통합 완료 판단: root, 2026-11-05.

관리 목록·입력 URL 구조 변경 없음. 완료 알림 형식 변경 없음: 삭제 서버 확정 결과와 unknown 보존 흐름을 유지한다. 기능 복구 시 이 보고서의 WB200 변경만 되돌리고 이전 미커밋 WB196~199 및 사용자 변경은 보존한다. 커밋·푸시·운영 배포는 이번 범위가 아니다.
