# 관리자 홈·로컬 로그인 검증

날짜: 2026-10-26 / 요구 R29 / 작업 WB11
계획: docs/superpowers/plans/2026-10-26-admin-home-login.md

## 역할

admin_session: 서버 세션·로그인·로그아웃·진열 중계·권한 테스트.
admin_ui: 로그인·홈·공통 메뉴·페이지 및 원문 보호·진열 화면 연결.
admin_review: 독립 소스 및 명령 검증, 배포 추적 확인.
조정 담당: 요구/문서/보드 갱신과 브라우저 전체 흐름 검증.

## 브라우저 결과

Edge 실제 실행 통과: 미로그인 /admin·진열·작업 보드는 로그인으로 이동, 원문과 진열 API는401. 외부 Origin 로그인/변경 요청403. 잘못된 키 거절, 개발 테스트 바로 로그인과 기존 키 로그인 성공. 무작위 HttpOnly·SameSite 쿠키를 사용하고 키는 쿠키값과 다르며 웹 저장소 비어 있음.

홈 메뉴로 진열/작업 보드 이동, 새로고침 로그인 유지, 320·390·1440px 가로 넘침 없음. 진열 제목 변경 저장·stale revision409·외부 Origin PUT403·원래 진열 복구 통과. 로그아웃 후 과거 쿠키 재사용401. 고객 홈에 관리자 메뉴 없음.

## 발견 및 보완

Next가 request.url의 호스트를 localhost로 정규화해 실제 브라우저 Host/Origin127.0.0.1과 차이가 있었다. 실제 Host를 엄격하게 검증해 URL protocol과 조합하고 Origin과 일치 검사한다. X-Forwarded-*를 신뢰하지 않는다. 회귀 테스트 추가 및 전체 브라우저 재실행 통과. 비밀값 없는 임시 진단 코드는 제거했다.

관리 route group 이동으로 보드 파일의 배포 추적이 누락되어 포함 패턴을 공통 경로로 수정했다. 비밀 환경 파일은 명시적 제외한다.

최종 독립 검증: 테스트 20/20·lint·typecheck·production build 모두 통과. nft12개에서 .env 파일 포함0, workboard.md 포함 확인. 실제 production 서버3111에서 테스트 로그인 버튼 없음, POST test403 및 쿠키 미발급, 진열 API/원문401 확인 후 임시 서버 종료.

## 제한

단일 프로세스 메모리 세션·8시간 유효, 웹 서버 재시작 시 만료. 운영 계정/역할·복구·지속 세션·로그인 시도 제한 등은 후속 범위다. 운영 reverse proxy의 scheme/host 전달은 배포 시 확인한다. 결제·재고·시안 기능은 이번 작업에서 구현하지 않았다. FastAPI 계약과 고객 공개 API는 유지한다. 커밋·푸시 미수행.
