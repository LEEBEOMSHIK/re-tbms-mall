# WB104 / R106 모바일 푸터

목적: 반복되는 등록예정·영문 구역 제목·긴 사업자 목록으로 길어진 모바일 푸터를 정리한다.
범위/담당: root shop-shell.tsx, customer-mobile.css, 디자인문서/보드; 별도 독립 검증. API/사업정책 변경 없음.
설계: 데스크톱4구역은 유지. 모바일은 브랜드→주요 링크2열→고객안내→사업자정보 native details→저작권. 실제 사업자 값은 생성하지 않고 기존6항목을 펼쳐 확인한다. 연락처 없는 현재 상태는 중복 placeholder 대신 안내문으로 표시.
수용/검증: 320/390px 링크44px/기본 및 큰글씨, details 클릭/키보드, 테마, 데스크톱 회귀, 타입/lint·보드 검사·독립 리뷰. 저장폼/관리화면분리는 해당 없음. 변경 파일만 되돌려 복구 가능.

## 결과
- 타입 검사 통과, shop-shell ESLint 통과, 작업 보드5/5 통과.
- CUA390px 다크 접힘/펼침 확인. Enter로 펼친 뒤 AX expanded 및6항목 노출 확인. 클릭 접기 확인.
- 320px 라이트/더 크게20px에서 긴 정책명이 한 글자만 줄바꿈되어 큰글씨 링크1열 전환으로 수정하고 실제 화면 재확인.
- 1440px 데스크톱4구역 유지 확인. 테스트 후 기본글씨/시스템테마·viewport 복원.
- 독립 footer_review: 코드/보드5 및 .local/wb104-footer.png, wb104-footer-expanded.png 육안 검토. 추가 차단 결함 없음.
- 실기기 테스트·정책 확정·실제 연락처 등록은 수행하지 않았다. 커밋/배포 없음.
