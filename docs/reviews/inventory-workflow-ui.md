# WB42 재고 흐름별 UI 검증

- 요구: R52 / 날짜: 2026-10-26
- 구현: inventory_ui / 문서·통합: 조정 담당 / 독립 검증: inventory_review
- 계획: docs/superpowers/plans/2026-10-26-inventory-workflow-ui.md

## 구현

입고 등록, 고객 판매 출고, 기타 출고·조정의 업무 카드와 직접 링크를 제공한다. 쿼리 없는 등록 URL이나 잘못된 flow는 업무를 먼저 선택하도록 한다. 입고와 고객 판매는 사유가 고정되고 기타 업무는 해당 사유만 제공한다. 선택 업무에 맞는 제목·수량·제출 버튼을 표시하며 업무 변경 시 옵션·수량·메모는 보존한다. 현재 수량, 증감, 예상 재고 요약을 제공한다. 목록의 사유 필터는 흐름에 맞춰 제한한다.

## 실행 근거

Edge 브라우저에서 합성 API 응답으로 검증: 업무별 링크, 누락/잘못된 flow, 입고·판매·증정·증가 조정의 코드와 부호, 공란 메모, 503 후 동일 요청 재시도, 저장 확인 후 이력 이동과 실제 원장 안내, 업무 전환 입력 보존 확인. 320/390/1280px 문서 가로 넘침 없음. 실제 재고 쓰기는 수행하지 않았다.

독립 검증: 웹 테스트 51개, 최종 lint·typecheck·production build 모두 통과(exit 0). 최종 문구·도움말 정리 후 브라우저 시나리오도 재실행하여 통과했다. 작업 보드 파서 5개 통과. API는 변경하지 않아 백엔드 테스트는 반복하지 않았다.

## 범위·복구

변경 파일: catalog-manager.tsx, catalog-forms.tsx, catalog-list.tsx, catalog.css, inventory/new/page.tsx 및 요구사항·디자인·결정·작업 보드 문서. API와 DB 변경 없음. 기존 미커밋 변경을 유지하고 이번 UI 변경만 되돌릴 수 있다. 공장별 발주·검수나 고객 배송 통합은 이번 범위가 아니다. 전체 접근성 감사·운영 연동은 미수행이다.
