# 화면 설정 패널 검증

2026-10-26 / WB22 / R35
계획: docs/superpowers/plans/2026-10-26-display-settings.md

inventory_ui는 TextSizeControl을 저장 크기 복원 전용으로 바꾸고 DisplaySettingsButton을 고객 헤더·관리자 헤더·로그인 제목 영역에 연결했다. 기존 상단 바를 제거하고 native dialog에 글자 크기 설정을 모았다. 조정 담당은 문서/보드/브라우저 통합, inventory_review는 독립 코드 검토를 담당했다.

Edge 통합 스모크(.local/display-settings-smoke.cjs) exit 0: 초기 옵션 숨김과 상단 바 제거, 톱니바퀴 열기, 모달 초기 포커스, Tab/ShiftTab 12회 순환, Escape/닫기/바깥 클릭 및 트리거 포커스 복귀를 확인했다. 초기 실행에서 native dialog의 Tab 경계가 body로 이동하는 동작을 발견해 명시적 첫·끝 순환을 추가한 후 전체 재실행했다.

최대 글자 크기에서320/390/1440px 패널 경계를 확인했고390px의 열림/닫힘 화면을 직접 시각 검토했다. 크기 저장/새로고침 복원/기본 초기화와 고객·관리자·로그인 각 진입도 통과했다. 상품 저장은 하지 않았다. API/DB·저장 키 계약은 유지하므로 API 검증은 반복하지 않았다. 전체 보조기기 인증을 주장하지 않는다.

디자인 시스템 v0.5와 요구/결정 기록을 갱신했다. 이후 화면 표시 설정도 같은 패널을 사용한다. 복구는 이번 UI·문서만 되돌리며 저장된 크기 및 서버 데이터 복구는 필요 없다.

독립 소스 검토 및 lint·타입 검사 exit 0. 작업 보드 파서5개 통과. 이번 표시 방식 변경은 실제 브라우저 흐름으로 검증했으며 전체 테스트·프로덕션 빌드는 재실행하지 않았다. WB22 완료로 기록했다. 다음 제안은 기존 WB13을 유지한다.
