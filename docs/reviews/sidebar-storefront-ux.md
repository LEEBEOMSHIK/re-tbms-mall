# WB168 · 관리자 메뉴 스크롤과 고객 상품 탐색

R23·R92 / 2026-11-04. 현재 로컬 3100/8100에서 관리자 내비게이션과 본문 스크롤을 분리하고, 다양한 상품 수·옵션·재고 상태에서 고객 화면을 확인한다. 메뉴 영역과 고객 목록은 각각 독립 구현하며 기존 상품과 수령·검수 검증 이력은 보존한다. 실행 범위는 로컬 공개 샘플 데이터·공통 UI·사용 가이드 start·작업 보드다.

검증은 관리자 PC 휠과 작은 화면, 고객 목록의 이미지/할인/색·사이즈/품절과 페이지 이동·검색·상세를 실제 화면에서 확인한다. 실제 구매와 결제는 시험 범위에 포함하지 않는다.
