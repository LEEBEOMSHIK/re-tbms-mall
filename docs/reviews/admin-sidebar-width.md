# WB171 · 관리자 메뉴 폭과 홈 진열 관리

R23 및 관리자 메뉴 구성(WB112) 후속. PC에서 작업 공간을 나눠 쓰고 MD가 홈 진열 목록을 바로 찾을 수 있게 한다. 관리자 사이드바·대시보드·메뉴 레지스트리·서버 호환 읽기·디자인 시스템·가이드(start, merchandising)가 범위다. 상품 진열 데이터나 게시 상태를 수정하지 않는다.

수용 기준은 마우스와 키보드로 폭 조절, 새로고침 후 복원, 기존 모바일 메뉴 유지, 독립 메뉴로 목록 진입 및 현재 위치 강조, 기존 표시 설정 보존이다. 폭 저장은 현재 브라우저의 로컬 설정이며 관리자 공통 메뉴 구성과 분리한다. 폭만 복구하려면 메뉴와 본문 사이의 경계선을 두 번 클릭한다.

3100 관리자 메뉴 조회 HTTP 200, 12개 ID와 사이트 관리 → 홈 진열 관리 → 리뷰 관리 순서를 확인했다. 독립 브라우저에서 PC 기본 240, 드래그 306, 방향키 290 및 새로고침 복원, Home 200/End 360, Enter·더블클릭 초기화를 확인했다. 모바일 390px에서는 손잡이 없이 메뉴에서 진입했다. 목록 7행 로드 후 PC 1440px와 모바일 캡처: .local/wb171-sidebar-desktop.png, .local/wb171-sidebar-mobile.png. start:1 가이드 이미지·표식도 갱신했다. 웹 235개, 서버 메뉴 36개, 타입·대상 lint 통과.

후속 확인: 3100 PC 다크 화면에서 메뉴 스크롤바를 드래그하면 목록만 이동하고 바로 옆 4px 경계를 드래그하면 너비만 변경됐다. 경계 위에서도 손잡이가 나타나지 않으며 키보드 조절·모바일 이동을 확인했다. 실제 캡처 .local/wb171-edge.png, start:1 이미지와 표식 5개 갱신.
