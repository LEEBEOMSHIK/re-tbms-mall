# WB107 / R107 프로필 사진
- 목적/담당: root, 독립 검증자. 로그인 후 소셜 사진 표시, 사람 아이콘은 미로그인에만 표시.
- 수정 범위: customer.py, 고객 DTO/BFF 파서, customer-session/CSS, 테스트 및 관련 문서.
- 계약: 선택 avatar_url(null 또는 안전한 HTTPS 공급자 CDN URL). 별도 customer_avatars 추가 테이블로 기존 profile 3열/계정/카트/세션 보존. Google picture, Kakao profile_image_url 사용, 재로그인 갱신·누락시 제거. 이미지 원본/공급자 토큰 저장 없음.
- UI: 28px 원형 사진, 미제공·로드 실패는 이름 첫글자(일반명은 계). 사진은 옆 이름과 중복이므로 장식 이미지. referrerPolicy no-referrer. 기존 이름/메일/키보드 보존.
- 검증: 합성 공급자 URL 경계/재로그인/세션 보존, 프론트 URL 검증, 타입/lint/독립 리뷰. 실 OAuth 재로그인은 사용자 확인 필요.
- 복구: 이번 소스 변경만 복구, 추가 테이블은 구버전에서 무시됨. 기존 데이터 삭제 없음.

## 검증 결과 (2026-10-30)
- API41 통과(6.31s, 합성 공급자·임시 DB, TestClient socketpair 제한으로 일반 로컬권한 사용). 신규 URL7개는 구현 전 실패→후 통과. Google 사진 저장/기존세션 조회/재로그인 누락 제거를 기존 프로필 보존 테스트에 추가.
- 타입검사·대상 ESLint 통과. 웹 고객17+보드5=22 통과.
- account_cart_review 독립 API41/고객웹17 통과. 전역 nav a display:grid가 로그인 링크 정렬을 덮는 문제 발견→고객헤더 범위로 구체성 강화. 문서의 사진 미사용 기존 기준을 대체 후 독립 재검토 통과.
- 한계: 이번 실계정 OAuth 사진 수신·브라우저 이미지 표시/실패 이벤트는 미실행. 사진 대체는 구현 코드 검토이며 브라우저 통과로 주장하지 않음. 실제 사진 수신/표시는 WB101 사용자 재로그인 확인에 포함.
