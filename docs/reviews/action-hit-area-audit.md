# WB204 · 호버·초점 강조 영역 전반 점검

- 요구 R107, 담당 root 구현·통합/별도 독립 검증.
- 목적: 텍스트 조작의 강조선이 글자/화살표에 붙지 않고 안정된 클릭 영역을 유지한다.
- 범위: 공통 customer-motion, cart-layout, 고객 로그인/탐색/푸터 및 디자인 시스템. API·권한·가격·상품 카드 구조 변경 없음.
- 분석: 공통 inset 2px 강조선은 padding0 텍스트 동작에서 내용과 접촉한다. PC1440/390의 17경로34보기에서 실제 CSS 치수 조사(`.local/wb204-runtime-audit.json`), 공통/관리자/공장 CSS 정적 검사(`.local/wb204-style-audit.txt`). 목록 후보는 결함 확정이 아니며 고유 형태/인라인 링크를 구분한다.
- 대표 경로: 홈, 상품 목록/상세, 장바구니, 로그인, 배송정보, 주문내역, 주문서 시안, 공개 배송안내, 관리자 홈/사이트/메뉴 목록·편집/주문/진열/디자인시스템, 공장 로그인. 주소록 인증 오류 화면은 데이터로 채운 본문 확인을 후속 보완한다. 공장 인증 후 전체 업무 실행은 이번 감사에 포함하지 않는다.
- 수용: 식별된 텍스트 조작 좌우12px 이상·높이44px 이상, 호버/초점 때 크기 불변, PC/모바일 넘침 없음, 링크/모달/옵션 기능 유지.
- 제외/유지: 아이콘44px 정중앙·옵션칩·수량스테퍼·상품제목/설명 내 인라인 링크는 일괄 padding을 넣지 않는다. 관리자 text-link는 inset 박스가 아닌 밑줄 방식이며 메뉴/탭/공장 nav는 기존 여백 확보. 상품 카드 레이아웃 변경 없음.
- 가이드: 고객 전용 치수 보정은 관리자 절차·캡처 영향 없음. 디자인시스템의 규칙 문서 동기화. 새 API·의존성 없음.
- 복구: WB204의 텍스트 조작 규칙/모바일 옵션 여백만 되돌리고 기존 미커밋 변경 보존.

## 구현·검증 결과 (2026-11-05)

- 변경 파일: `apps/web/src/components/customer-motion.css`, `apps/web/src/components/cart-layout.module.css`, `docs/design-system.md`, `docs/templates/review.md`, 본 기록, `workboard.md`.
- 고객 텍스트형 이동 링크·푸터·모바일 메뉴·계정 재조회에 좌우12px/높이44px을 확보했다. 모바일 옵션 변경의 padding0 덮어쓰기를 제거했다. 기존 토큰·호버 애니메이션을 유지하며 공통 규칙과 검토 항목을 문서화했다.
