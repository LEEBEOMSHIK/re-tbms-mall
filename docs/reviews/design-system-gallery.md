# WB176 관리자 디자인 시스템 참고 화면

D09와 공통 UI 기준을 실제로 비교하는 관리자 전용 화면을 추가한다. 프런트의 보호 경로 design-system, 관리자 메뉴 레지스트리 및 호환 처리, 관리자 가이드 design-system과 실제 화면 캡처를 변경한다. 입력과 완료 예시는 화면 로컬 상태에서 동작한다. 수용 기준은 보호 경로와 기존 메뉴 설정 보존, 분류 및 구성 요소 조작, PC·모바일 레이아웃과 가이드 확인이다. 기본값 복귀는 새로고침으로 확인할 수 있다.

3100 프로젝트 메뉴에서 12개 메뉴 설정의 디자인 시스템 진입 및 비로그인 로그인 전환 확인. PC 1440 라이트/모바일 390 다크에서 전체·분류 4개, 입력 확인/초기화/오류, 선택, 도움말과 완료 예시 복귀를 독립 검증했다. 서버 쓰기 0건. API 메뉴 36개와 웹 메뉴/가이드/보드 20개, 타입 검사와 대상 lint 통과. design-system:0 가이드 캡처를 추가하고 기존 메뉴 관련 가이드 캡처 3개를 갱신했다. 화면 증거 .local/wb176-pc.png 및 .local/wb176-mobile.png.
