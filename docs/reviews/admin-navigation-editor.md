# WB175 관리자 메뉴 관리 및 편집

R109. 그룹 순서를 살피고 한 그룹의 메뉴를 편집할 때 이름과 조작 버튼을 함께 읽을 수 있게 한다. 기존 화면에서는 긴 그룹 이름 필드와 반복 설명이 공간을 차지했고, 메뉴 목록의 하위 li 전체를 꾸미는 규칙이 소속 그룹 드롭다운의 선택지까지 두 열로 만들었다.

변경 범위는 navigation/menu-manager.tsx, menu-manager.css, 디자인 시스템과 관리자 가이드 navigation이다. 기존 메뉴 조회·저장 계약과 충돌 복구를 사용한다. 확인 항목은 좁은 영역에서의 그룹 선택, PC 드롭다운, 그룹 간 이동·순서 조정·표시, 저장과 입력 복구, 저장 결과 포커스다. 로컬 공용 메뉴 설정은 실제로 변경하지 않고 쓰기 응답은 합성 검증으로 확인한다.

3100 Edge 1440px 및 390px에서 첫 그룹 순서 이동 후 선택 유지, 신규·삭제 후 포커스, 편집 중인 그룹 밖의 빈 이름 검증과 포커스, 다른 그룹으로 메뉴 이동, 기본 구성 복원, 저장 충돌 후 최신본 확인·입력 보존 및 재저장을 확인했다. 완료 제목 포커스와 편집폼 숨김을 확인했다. 두 폭에서 쓰기 요청은 브라우저에서 모두 모의 응답 처리했다. 타입과 대상 ESLint, 관리자 메뉴 테스트 통과. 화면 관련 변경을 복구할 때는 메뉴 관리 컴포넌트·스타일·가이드와 캡처를 함께 복구한다.
