# WB209 / R107 관리자 옵션 선택 UI

- 사용자 지시: 색상·사이즈는 일반 선택 컨트롤과 구분하여 기존 쇼핑몰 전용 표현을 사용한다.
- 범위: catalog-forms.tsx, catalog.css, 가이드 catalog:2/원문, 디자인 시스템·보드. root 구현, hold_ui 독립 검증.
- 원형 ColorChip·영문 색상명, productSizeLabel 기반 S/M/L 배지. 기본48px 클릭 영역·선택 테두리/배경·포커스. 미지정색은 공통 사선 칩/원래 이름 유지.
- 기존 native checkbox·label·toggle·전체선택·선택해제·SKU 조합·저장 로직 보존. 실제 데이터 쓰기/새 패키지 없음.
- 수용: PC/320 선택·해제·전체선택·키보드·넘침/테마·미지정색 확인. 기존 catalog 계약·표시변환·가이드검사 및 타입/lint.
- 복구: 본 작업의 전용 옵션 UI와 가이드만 되돌린다. 기존 미커밋 작업 보존.

## 검증 결과 · 2026-11-06

- 공통 ColorChip/색명 변환·productSizeLabel을 재사용했다. 체크박스는 숨김 입력과 전체 label 클릭으로 유지하여 다중 선택 및 기존 조합을 보존했다.
- 실제3100 캡처에서 색상 원형/아래 영문명, 알파벳 배지, 선택 테두리·배경을 확인했다. 초기에 발견한 공유 flex-basis의 타원형(26×30)과 기존 label 규칙의 배치 충돌을 수정했다. 색상 전용 투명 테두리/64px 규칙 우선순위도 보정했다.
- 독립 hold_ui PC1440/320: Space, 전체선택/해제, 미지정색 사선/원래명 유지, 가로 넘침 없음 확인. `.local/wb209-independent.cjs`·관련 캡처. 실제 데이터 쓰기 없음.
- 타입·수정파일lint·catalog/색상/사이즈/guide15개 통과. 최종 가이드/보드9개 재검증 통과. API·저장 로직은 변경하지 않아 API 전체검사 미실행. 모바일은 Chrome viewport 검증이며 실기기는 미실행.
- catalog 가이드 원문 및 catalog:2 실제 캡처·좌표 갱신, 인증 이미지 로드/시각 정렬 확인. 디자인시스템 문서에 색상·사이즈를 일반 선택 UI의 예외로 명시했다.
