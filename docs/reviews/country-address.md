# WB47 국가별 주소 검증

2026-10-26 / R57. 구현: inventory_api(서버), inventory_ui(주소폼), 조정(검색 연동·통합). 독립 검증: inventory_review.

## 구현

국가 미지정 기본값을 유지하고 249개 국가/지역 코드를 선택한다. 대한민국은 공식 카카오 주소검색과 직접입력을 모두 제공하며 해외는 지역·도시·주소1/2·우편번호를 직접 입력한다. 국가전환에서 기존값을 삭제하지 않는다. 검색 결과는 명시 선택한 도로명/지번과 우편번호만 적용하고 상세주소/지역/도시를 보존한다. 상세주소로 포커스를 옮기고 적용 내용을 알린다.

검색은 클릭 시만 공식 SDK를 로드하고 본문에 삽입한다. 실패·취소 시 직접입력이 가능하며 오래된 응답/언마운트/저장중 응답을 차단한다. 외부 응답 형식·길이를 검증한다. 공급자 로고를 숨기지 않는다.

## 실행 증거

- 독립 API233개, 웹61개 테스트 통과. 국가 허용목록·null/길이·누락/clear·국가전환·기존주소·원장·이관 보존 포함.
- Edge 모의 서비스: 기존 미지정주소 복원, 페이지진입에서 외부스크립트 미로딩, 검색실패/재시도, KR선택 시 우편/주소만 반영, 상세포커스, 해외저장, 국가전환 모든기존주소보존, 로딩중 저장실패 후 검색회복, 국가전환 뒤 늦은응답무시 확인.
- 390/1280px, 라이트/다크·확대글꼴에서 문서 가로 넘침 없음. 폼 시각 확인.
- 공식 SDK와 실제 postcode.map.kakao.com 검색 iframe 로드 성공. 실제 서비스에는 검색어/개인정보/공급처 저장을 제출하지 않았다. 실제 검색결과 선택은 미실행이며 선택 콜백은 모의 응답으로 검증했다.
- 실제 schema8 반영 후 suppliers/products/skus/movements의 모든 이전 컬럼이 백업과 동일. FK·integrity_check 통과. 실제 공급처·재고 테스트 쓰기 없음.
- 독립 검토에서 로딩 중 disabled 전환 후 로딩 상태 잔류 문제를 발견해 세대/잠금/표시 초기화 추가 후 브라우저 재현 통과. lint 경고도 정리했다.

최종 독립 lint(경고0)/typecheck/production build 모두 exit0. 작업 보드 파서5개 통과. 국가 목록은 정적 ISO alpha2이며 갱신은 별도 검토한다. 외부 iframe의 전체 접근성·모든 브라우저·실서비스 검색결과를 검증한 것은 아니다.
