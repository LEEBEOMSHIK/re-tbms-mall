## 제한·복구

백업은 .local/catalog-before-v3-20261026-011717.sqlite3(schema2). 실제 DB는 앞선 테스트 데이터가 정리된 상태이며 비어 있지 않은 기존 DB 이관은 독립 API 테스트로 별도 검증했다. 테스트 도구와 캡처는 .local/에 있어 Git 제외다.

API를 중지하고 현재 v3도 백업한 뒤 호환 코드와 v2 백업을 함께 복구한다. 이후 입력분을 먼저 보존/재적용한다. 내부명 접두사와 계절 코드는 최초 발급 기준이며 현재 속성과 다를 수 있다. 기존 미지정 값을 자동 추측하지 않는다. 고객 게시·대시보드 실재고 연결·실결제·운영 DB·외부 연동은 기존 후속/미정 상태다. 전체 스크린리더·운영 부하 시험은 미실행이다. 새 의존성·Docker·커밋·푸시·배포 없음.
