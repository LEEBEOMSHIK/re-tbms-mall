# WB111 관리자 사이드바와 화면 밀도

요구/목적: 사용자 요청으로 관리자 계정/메뉴를 왼쪽에 배치하고 큰 UI 원인을 점검한다. 담당 root, 별도 독립 검증. 범위: admin-navigation.tsx, protected/layout.tsx, admin.css, dashboard.css, 문서. 계약: 기존 인증·로그아웃·경로 그대로; 관리자 이름 데이터가 없는 토큰 세션이므로 관리자 세션으로만 표시. 본문과 로그인 페이지 분리. 데스크톱240px sidebar, 작은 화면 접기 메뉴. 제목28px(기본16px 기준), 대시보드 패널20px padding. 44px 조작영역과 사용자 글자 확대 유지. 의존성 기존 admin shell. 수용: 메뉴활성/탐색/반응형/설정 접근, 사용자 확대설정 보존. 검증: 타입/관련 테스트/브라우저/독립 리뷰. 복구: 이번 shell/CSS 변경만 되돌림, DB 변경 없음.

사전 측정: 사용자 Chrome127.0.0.1:3100/admin DOM text-size=large, root/body18px, h1 36px, viewport1440 CSSpx, DPR2. 브라우저100%와 사이트112.5% 설정은 별개이며 OS배율은 추정하지 않는다. 설정을 강제로 초기화하지 않는다.
