# WB178 디자인 레퍼런스 적용
D09. 기존 CSS 변수와 공통 폼·상태 컴포넌트에 라이트/다크 색과 선택·입력 외곽선을 적용하고 고객 상품 필터·옵션, 관리자 탐색·업무 카드, 공장 메뉴·대시보드의 지역 스타일을 맞췄다. 디자인 시스템의 태그 미리보기는 이름·색상·광택만 화면 안에서 변경한다. 가이드 design-system:0을 갱신했다.

실제 3100 Edge PC 1440 라이트 및 모바일 390 다크에서 미리보기 변경, 상품 목록 필터와 상품 상세, 관리자 사이트 관리 및 공장 브랜드 자료실을 확인했다. 공통 폼에서 키보드 선택·Escape·완료 제목 포커스, 강제 색상 체크 표시와 동작 줄이기 전환 시간도 확인했다. 주요 버튼 글자/배경 대비는 라이트 7.47:1, 다크 8.66:1, 보조 버튼 8.09:1과 9.99:1, 외곽선/기본면 3.99:1과 5.33:1이다. 이 수치는 해당 색 조합의 측정 결과다.
