# WB166 관리자 사이드바 및 수령·검수
관리자 레이아웃 마운트와 명시적 재시도 시 설정 조회. 메뉴 저장 이벤트는 즉시 반영. 경로 이동마다 상태 요청을 보내던 구조와 BFF 15초보다 짧은 브라우저 10초 타임아웃을 수정했다. 서버/네트워크 일시 오류에 한 번 자동 재조회, 인증 실패와 응답 형식 오류는 구분한다. 저장 데이터 변경 없음. 복구 시 해당 클라이언트 변경만 되돌린다.

실제 로컬 3100 및 8100으로 검증했다. 별도 테스트 세션 메뉴 200 두 번, 그룹 항목 11개, 실제 수령·검수 경로에서 조회 오류 문구 없이 메뉴와 빈 발송 목록 안내 확인. 이전 캡처의 네트워크 상태·응답 코드는 확인할 수 없어 당시 원인을 단정하지 않는다. 공장 가이드 factory의 발송 등록→수령 흐름을 보완했다. 기존 버튼 위치는 동일하다. 캡처 .local/wb166-admin-shipments.png. 관련 메뉴/가이드 테스트 9개 통과.
