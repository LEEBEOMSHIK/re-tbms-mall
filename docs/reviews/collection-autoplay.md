# WB170 · 컬렉션 자동 넘김 및 MD 진열 확인
R23. 고객 홈 스튜디오 샘플 컬렉션의 자동 전환과 재생 버튼을 수정한다. 관리자 기능은 기존 실제 진열값을 보존하고 설정 경로·노출 조건을 확인한다. 수정 파일은 product-carousel.tsx, 디자인 시스템과 보드다. 관리자 편집·저장 절차가 바뀌지 않아 관리자 가이드 캡처에는 영향이 없다.

변경 전에 3100에서 세로 휠로 들어온 뒤 6.13초간 묶음이 그대로였고, 재생 버튼을 클릭한 뒤에도 6.22초간 바뀌지 않았다. 모든 휠·터치 시작이 수동 정지를 걸고 영역 전체의 hover와 focus가 재생을 막는 조건을 분리했다. 되돌리려면 이번 자동 재생 이벤트 처리 변경만 복구한다.

독립 브라우저 검증 결과: 1440px PC 세로 휠 진입 후 4.85초 뒤 02/02, 390px 모바일 세로 터치가 끝난 뒤 02/04. 일시정지 후 5.5초 유지, 재생 버튼에 포커스를 둔 채 PC 5.18초/모바일 5.13초 뒤 재개. 가로 수동 이동 후 재생 정상, 키보드 카드 포커스 중 정지 확인. 타입 검사·대상 ESLint 통과.
