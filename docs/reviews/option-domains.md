# WB30 색상·사이즈 기준정보 검증

- 요구: R40 / 계획: docs/superpowers/plans/2026-10-26-option-domains.md
- 구현: inventory_api(API/이관), inventory_ui(UI), 조정 담당(TS/BFF/문서).
- 독립 검증: inventory_review. API 126개, 웹 40개, lint·타입 검사·프로덕션 빌드 통과. 소스 검토상 남은 차단 이슈 없음. 브라우저와 실제 DB 확인은 조정 담당이 수행.

## 범위

FastAPI 기준정보 생성·수정/활성·순서 관리, SKU ID 참조와 서버 코드 생성, schema4 이관. Next.js 응답 검증/BFF, 옵션 콤보박스·빠른 추가·별도 관리 화면과 관리자 진입점, 디자인 시스템/요구/API/결정 문서.

## 확인된 증거

- 독립 API 테스트 126개 통과. 인증, 입력 타입/범위, 중복·버전·동시성, 비활성/잘못된 종류/없는 참조, 긴 자동 코드, 기준정보 이름 변경, 기존 SKU/원장 보존 이관과 실패 롤백 포함.
- 실제 로컬 Edge+BFF: 미인증401·다른Origin403·빈 입력422·없는ID404·기존 자유입력 SKU 요청422. 실제 catalog 조회 전후 동일, 성공 쓰기는 수행하지 않음.
- Edge 모의 API 흐름: 활성 콤보박스/비활성 제외, 읽기 전용 자동 코드, 빠른 추가409입력 보존→201후 자동 선택, SKU ID만 전송, 창 focus 재조회와 작성값 보존, 기준정보 생성/이름 수정/비활성화 통과.
- Edge 320/390px 페이지 전체 가로 넘침 없음, 콤보박스 키보드 열기/이동/Escape 확인. 모든 보조기술이나 실제 모바일 기기를 검증한 것은 아님.
- 실제 DB 이관 전 온라인 백업: .local/catalog-before-v4-20261026-031451.sqlite3. schema4 전환 후 상품2개 보존, 기존 SKU0개·원장0개, foreign_key_check 이상 없음. 데이터가 있는 이관은 별도 합성 테스트에서 검증.
- 브라우저 스크립트는 .local/option-domain-bff.cjs, .local/option-domain-browser.cjs(ignored). 모의 브라우저에서만 성공 생성/수정 수행.

## 복구와 제한

앱을 중지하고 이관 전 DB와 이전 코드를 함께 복구한다. 이관 후 실제 쓰기가 있으면 먼저 추가 백업/데이터 이전 계획을 수립하며 이전 백업으로 덮어쓰지 않는다. 삭제 없는 기준정보 사용 중지와 기존 SKU 표시값 보존 정책이다. 운영 DB/게시/가격/결제 정책은 이번 범위가 아니다. 커밋·푸시·배포하지 않음.
